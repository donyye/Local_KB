1.  FC Topologies

  ---------------------------------------------------------------------------------------------------------------------------------------------------- -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  Point-to-Point                                                                                                                                       通讯效率最高【N类型】
  FC_AL(光纤环)       支持126(2的7次方-2)个设备:如果其中一个设备down了,会自动跳过【NL类型(L代表Loop】
  FC_SW(交换式光纤)   交换式可以定义交换机上的每个接口的类型(是P2P还是交换式)【F or FL 类型】
  ---------------------------------------------------------------------------------------------------------------------------------------------------- -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

FC_AL:

AL-PA 环路的物理地址优先级最高0x01,优先级最低0xef, 0x00保留给交换机

环路的Loop ID 优先级最高125, 优先级最低0, 126保留给交换机

\*没有交换机的话只能是P2P 或者 AL拓扑

FC_SW:

[ Point]与Switch连的接口叫N,交换机这端端口叫F

[ Loop]与Switch连的接口叫NL,交换机这端端口叫FL

[ ]交换机之间连的端口叫E, Expansion

[ ]交换机上的端口没有接任何设备的时候,这个时候叫做G(General,通用)=E,F ; U=G,FL

[ ]交换机的寻址: Domain ID(交换机ID) + Port ID + Loop ID[  -]通过光纤交换机Name Server建立Table

\*检查Name Server里是否有这条记录

安装步骤

1\. 通过串口线将两者进行连接

2\. 确保交换机已经加电

3. 通过ipAddrSet命令设置IP地址[  (]默认IP地址:10.77.77.77)

\*命令对大小写敏感,但是全小写或全大写也可以.

 

\*不是所有端口都能用的,额外端口是需要License激活的

 

  ------------------------- -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  \>ipaddrshow              IP地址查看
  \>ipaddrset               IP地址设置
  \>licenseshow             License查看
  \>licenseadd xxxxxxxxxx   License添加
  \>supportshow             Supportlog -\> 转发给Brocade
  \>firmwaredownload        固件下载,支持FTP/SCP
  \>fabricprincipal         设定首要的交换机
  ------------------------- -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

fabricprincipal \--show -p 0x01 -f

 

\*尽量每块HBA都放到各自的Zone里

[     Brocade Zone]

Software Zone 针对设备

1.查看WWN上对应的设备,确认是WWN几,为其创建alias name

2.用别名来创建Zone

一个Zone里只有一块HBA的,称为Single[  initiator  Zone]

3.配置Zone -\> Save Config -\> Enable Config

Brocade只有一个config文件,重新Enable Config会导致停2-3s

Hardware Zone 针对交换机上的端口(端口号或者是WWPN)

多数情况下做Software Zone

 

不同厂商交换机级联可能会做不起来.
