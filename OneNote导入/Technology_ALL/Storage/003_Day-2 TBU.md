磁带库:

- 1.磁带机电路板(刷FW,控制替换磁带,磁带脏了更换)
- 2.槽位
  - data slot 
  - I/O(mail) slot 
- 3.机械臂(可以270°转动)
- 4.电源/风扇
- 5.磁带库控制卡(controll / remote / management) -接在一块背板上
- 6.标配一个磁带机(进行备份动作) ; 可选两个磁带机(半高);全高只能接一个
- 7.前置控制液晶面板
- 8.磁带读可以往前读两代,写可以往前写一代.

 

TL2000/4000

 

1.TL2000只有左边下面的一个槽位可以弹出磁带

2.可选iSCSI卡接在背板上

3.支持SCSI和FC的LTO3磁带机;LTO4,5,6磁带机仅支持SAS和FC.

4.23 data slots ; 1 I/O Station slot(可再配1个 clean slot)

5.WORM media , 写一次读多次介质

6.Bar Code - 磁带机条码[  ]在restore的时候很有用

读6位读不出来是LTO几，读8为才可以读出来。

7.运送,拿放磁带的时候要特别小心,不能剧烈晃动,不能可能造成卡带.

8.如果用FC的话,需要将FC Tape Support enable起来（在FC HBA卡上设置）

9.磁带机/磁带机电路板/控制卡

10.Web界面默认用户名admin, 密码secure
