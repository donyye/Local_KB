R920 / R910[  ]comparison

Sunday, March 30, 2014

7:44 PM

R920 is the direct replacement for R910, with more drive bay options, Gen3 PCIe slots, larger memory footprint, dual 12Gb RAID controllers option and Express Flash drives support (PCIe SSD) and Dell iDRAC7 Enterprise.

- Flexible configuration options to configure exact customer requirements.[  ]
- More of everything, but buy only what you need
- Provides the flexible LOM with NDC options that support minimum 4x GbE with options for 10GbE, Intel/Broadcom, Copper/Fiber. 
- PERC9 12Gb 
- HA features Supports new Intel IvyBridge EX processors (Intel Xeon E7 2800/4800/8800 v2[  )]
