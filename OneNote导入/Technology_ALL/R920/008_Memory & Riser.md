系统内存包含 96 个内存插槽，分为八个内存提升卡，拆分为四组，每个处理器两个提升卡。

每个内存提升卡有：12 个 DIMM 插槽，排列为四个通道。在每个通道中，第一个插槽的释放拉杆标记为白色，第二个插槽的释放拉杆标记为黑色，第三个插槽的释放拉杆标记为绿色。

内存提升板 A 和 B 中的 DIMM 分配给处理器 1，内存提升板 C 和 D 中的 DIMM 分配给处理器 2，内存提升板 E 和 F 中的 DIMM 分配给处理器 3，内存提升板 G 和 G 中的 DIMM 分配给处理器 4。
