  2019年11月12日发布

  - 先升级驱动，再升级微码，最后重启生效.

   

  - 安装kmod rpm包或者tar源代码包，二选一即可
  - Kmod rpm包
    - 优势：安装简单（执行rpm --ivh xxx.rpm即可安装）；
    - 缺点：只能限定安装在较新的RHEL/SLES等发行版上
  - Tar源代码包优势：
    - 优势：不局限于特定的较新的发行版；
    - 缺点：如果客户没有完整安装OS编译库文件的话，安装步骤稍复杂（需搭一个本地yum源安装编译所需的依赖库）
  - 用安装OS对应的ISO IMAGE配置本地的YUM源（不要用网络上的yum源），然后执行第2步安装一些必要的依赖包
  - \# yum install kernel-devel gcc libibverbs-utils perftest libibverbs-devel net-tools pciutils bzip2 unzip
  - 编译并安装下载的驱动源代码文件
  - #unzip Linux_Source_45xxx_41xxx_xxx.zip
  - #tar jxvf fastlinq-8.xx.xx.x.tar.bz2
  - #cd fastlinq-8.xx.xx.x
  - #make install
  - #make libqedr_install //RHEL or CentOS7.3及以前的版本请执行这一步；7.4及以后的版本不需要执行
  - #rmmod qede
  - #rmmod qed
  - #modprobe qed
  - #modprobe qede
  - #modprobe qedr(按需，如果需要跑RDMA的话)
  - 升级网卡微码的步骤（Linux）
    - #chmod 777 ./Network_Firmware_VNC6M_LN64_15.01.00_A00-00.BIN
    - #./Network_Firmware_VNC6M_LN64_15.01.00_A00-00.BIN
    - #reboot[  //]重启生效
  - 固件也可以直接在14G服务器的iDARC web管理页面中直接升级（步骤略）
