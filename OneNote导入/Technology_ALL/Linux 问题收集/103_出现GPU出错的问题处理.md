1. Operating System Upgrade\
当前系统运行的是Red Hat Enterprise Linux 9.1，已达到支持终止。我们建议升级到受支持的版本，以减轻潜在的操作系统级别错误，并确保持续的支持和稳定性。

The current system is running Red Hat Enterprise Linux 9.1, which has reached End of Support. We recommend upgrading to a supported version to mitigate potential OS-level bugs and ensure continued support and stability.

<https://access.redhat.com/support/policy/updates/errata>\
 

 

2. Enable NVIDIA ECC\
要在NVIDIA GPU上启用纠错代码（ECC），请执行以下命令：

To enable Error Correcting Code (ECC) on NVIDIA GPUs, please execute the following command:

\$sudo nvidia-smi \--ecc-config=1\
\
 

[ ]您可以使用以下命令验证ECC状态：

3\. You can verify the ECC status using:

\$nvidia-smi -q -d ECC\
 

 

4. Force GDM to Use Xorg[   ]强制GDM使用Xorg

要将GDM配置为使用Xorg而不是Wayland，请执行以下操作：

To configure GDM to use Xorg instead of Wayland:

 

Edit the GDM configuration file:[   ]编辑GDM配置文件：

\$sudo vi /etc/gdm/custom.conf

 

Uncomment or add the following line:[    ]取消注释或添加以下行：

WaylandEnable=false

Restart the GDM service:[    ]重新启动GDM服务：

\$sudo systemctl restart gdm
