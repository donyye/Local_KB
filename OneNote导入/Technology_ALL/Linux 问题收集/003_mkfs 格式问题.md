mkfs 格式问题

Monday, May 05, 2014

5:09 PM

在Red Hat Enterprise Linux v6.4，格式化EQL上的Volume时，可能会遇到"光标一闪一闪，格式化无法继续进行"

这个问题仅仅在RHEL6.4出现，6.3、6.5都不会遇到这种问题

![[Technology_ALL_Linux 问题收集_003_mkfs 格式问题_001.jpg]]

 

![[Technology_ALL_Linux 问题收集_003_mkfs 格式问题_002.jpg]]

 

解决方法：格式化硬盘时，加上参数 --E nodiscard

![[Technology_ALL_Linux 问题收集_003_mkfs 格式问题_003.jpg]]

 

![[Technology_ALL_Linux 问题收集_003_mkfs 格式问题_004.jpg]]

| Redhat 回复：\                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| 有关discard:                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| 在存储上，写入数据时，系统会通知存储先将以前的擦除，再将新的数据写入到磁盘 中。而在删除数据时，系统只会在此处做个标记，说明这里应该是没有东西了，等到真正要写入数据时再来真正删除，并且做标记这个动作会保留 在存储缓存中，等到存储空闲时再执行。如果存储是SSD并确认SSD支持Trim后，在删除数据时，不会向SSD通知删除指令，只使用 Volume Bitmap来记住这里的数据已经删除。Volume Bitmap只是一个磁盘快照，其建立速度比直接读写硬盘去标记删除区域要快得多。这一步就已经省下一大笔时间了。然后再是写入数据的时候，由于NAND 闪存保存数据是纯粹的数字形式，因此可以直接根据Volume Bitmap的情况，向快照中已删除的区块写入新的数据，而不用花时间去擦除原本的数据。  |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| 使用nodiscard这个参数，即在格式化存储时，不将格式化指令真正发向存储，而应该是只做一个标记，表示存储是空的。                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
