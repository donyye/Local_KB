网络名称改变

2022年12月23日

16:35

 

Message 记录，网卡名字会重命名失败

eth0: Failed to rename network interface 2 from \'eth0\' to \'eth1\': File exists

 

![[Technology_ALL_Linux 问题收集_081_网络名称改变_001.png]]

 

 

需要通过udev命名方式来吧名字改成emX，不使用eth0方式命名。

因为eth0系统自动命名会有和多问题，有可能会导致冲突，建议改成其它名字。

不管事ubuntu或SUSE、redhat等都会有这种问题。它与目前系统并行启动有很大关系。
