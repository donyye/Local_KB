  Hi, 海康各位同事， 

   

      感谢各位在本次事件的配合和支持。此事在以后，海康生产线上如有任何进展（安装其它同配置的服务器是成功还是失败），也请与我沟通，以便及时反馈及时解决。 谢谢！

   

  继5月15日一台R740 JJDJWW2存在安装操作系统过程结束后，重启出现uEFI 0082告警提示无法进入到操作系统之后，在5月22日再次发现R740 JJDFWW2 JJDH4W2 两台出现同样技术现象。在5月24日戴尔再次上门服务后，在现场确认本现象与BIOS中的OS Watchdog timer设置有关。

   

  现象：

  R740在安装海康定制版本的CentOS 7.6后，能正常进行"无人参与"的操作系统安装过程，但安装完成后重新reboot之后系统出现下图uEFI 0082，之后无论按何功能键均不能正常导入到操作系统引导界面。

   

  此故障现象解决过程：

  1.  R740 JJDJWW2 JJDFWW2 JJDH4W2 在安装海康定制版CentOS后均有此现象;R740 608C6W2 一次性安装成功。无论采取iDRAC远程虚拟镜像方式还是现场流程要求的KVM映射方式，均是同样现象。
  2.  DELL人员使用之前邮件所说的下载网址下载RHEL 7.6和 CentOS 7.6版本，在R740 JJDFWW2 JJDH4W2 上使用iDRAC远程虚拟镜像方式能进行正常安装，正常重启，正常引导至操作系统;且重启三至四次后，仍能正常运行。JJDH4W2在安装RHEL 7.6的情况下，设置电源关机两小时后重新开机，随即出现进入到uEFI0082界面上。
  3.  为JJDFWW2升级BIOS至2.1.8，故障现象依旧。
  4.  R740 JJDJWW2在5月17日再次安装时，由同一人使用KVM安装方式安装海康版本CentOS 7.6，一次性安装成功，已经装箱运至项目现场。
  5.  查以下出厂相关BIOS版本，着重将诊断方向转至BIOS设置中的' OS watchdog Timer"。在三台R740上进行十几次测试，只要更改OS watchdog Timer = Enable， 安装操作系统必出现uEFI0082 错误、能正常启动的情况下再次重新启动必出现uEFI0082错误；只要更改OS watchdog Timer = disable情况下，安装操作系统必定成功，能正常启动情况下再次重新启动必定成功，一旦改为OS watchdog Timer = Enable，就必然失败。 此测试现象在三台服务器608C6W2 JJDFWW2 JJDH4W2是一致的。

          

  ::: 
    -------------------------------- ------------------------------------------ -------------------------------------------------------------
    ST   BIOS version   OS watchdog Timer default value
    608C6W2                          1.6.13                                     Disable
    JJDFWW2                          2.1.6                                      Enable
    JJDH4W2                          2.1.6                                      Enable
    JJDJWW2                          2.1.6                                      Enable
    -------------------------------- ------------------------------------------ -------------------------------------------------------------
  :::

   

   结论： 

  现场结论认为BIOS中的设置OS watchdog Timer的值是影响安装OS 7.6能否成功的决定性因素。

  现场猜测BIOS中OS Watchdog Timer的默认值在BIOS version 1.6.13上是disable，但在BIOS version 2.1.6中，其默认值为enable。此猜测与前期同配置的R740二十多台均能正常安装出货，但只有5月15日以来的三台服务器出现此现象。

   

   

  行动建议： 

  1.  提请海康生产线协助观测以后服务器安装CentOS 7.6的情况，如果遇到uEFI0082问题时按以下方式在现场更改BIOS设置中的OS Watchdog Timer值为disable再行尝试。 
  2.  戴尔会给出同样配置的R740，在4月26日之后出厂的服务编码列表。

  以下更改OS watchdog Timer设置操作步骤：

   

  1、开机或者重启服务器。

  2、开机自检时，屏幕左上角出现提示F2\\F10\\F11\\F12等功能键提示时，按F2键进入硬件System Setup中。

  3、在System Setup里面，选择System BIOS并进入。

  ![[Technology_ALL_Linux 问题收集_050_系统启动出现uEFI0082错误且进入不了OS_002.jpg]]

  4、在System BIOS种，选择Integrated Devices.

  ![[Technology_ALL_Linux 问题收集_050_系统启动出现uEFI0082错误且进入不了OS_003.jpg]]

  5、在Integrated Devices中，找到OS watchdog Timer选项，并按回车，将键值更改为disable。

  ![[Technology_ALL_Linux 问题收集_050_系统启动出现uEFI0082错误且进入不了OS_004.jpg]]

   

  ![[Technology_ALL_Linux 问题收集_050_系统启动出现uEFI0082错误且进入不了OS_005.jpg]]

  6、按ESC退出，并save后退出System Setup，服务器重启。
