OMNIA 1.0

2021年3月19日

9:31

Omnia is a new open source project started by Dell Technologies to simplify and speed the process of building clustered environments for mixed workloads including AI, Data Analytics and HPC. Omnia's first full release (1.0) is available now, and automates operating system provisioning, deployment of accelerator drivers, installation of Slurm and/or Kubernetes, and deployment of machine learning development platforms including JupyterHub and Kubeflow.

 

ProSupport for Omnia is a new paid support offering from Dell Technologies which provides customers with direct access to support services should they need assistance with their Omnia clusters.
