- [https://access.redhat.com/solutions/205653](https://access.redhat.com/solutions/205653)

  Environment

  - Red Hat Enterprise Linux 6
  - gdm

  Issue

  - Why I am getting a tilted gdm login screen after system update ?
  - Login screen changed to vertical mode as shown below:

  ![[Technology_ALL_Linux 问题收集_014_斜屏_001.jpg]]

  Resolution

  - Create /etc/X11/xorg.conf file with following content

  [Raw](https://access.redhat.com/solutions/205653)

  cat \> /etc/X11/xorg.conf

  Section \"Screen\"

          Identifier \"Builtin Default mga Screen 0\"

          Device     \"Builtin Default mga Device 0\"

          Monitor    \"Monitor0\"

          DefaultDepth     24

          SubSection \"Display\"

          Modes \"1024x768\" \"800x600\" \"640x480\" \"720x400\"

                  Depth     24

          EndSubSection

  EndSection

  Press CTRL+D to save and exit the window.

  - After changes reboot the system.

  Root Cause

  - Screen resolution was increased to 1366x768

  Diagnostic Steps

  - Try booting the system with old kernel from the grub menu? Then, login in the GUI mode and check whether you are able to see the display properly after login. Also try to lower down the display resolution by clicking System -\> Preferences -\> Display option. 

  If the issue persist, then boot the system into runlevel 3 and use command below

  [Raw](https://access.redhat.com/solutions/205653)

  \# startx

  - See whether the issue is reproducible by creating new user.
  - Get the output of below command from root user and affected user.

  [Raw](https://access.redhat.com/solutions/205653)

  \# xrandr

  - Try to switch the tty consoles and check whether the issue persist.
  - Create /etc/X11/xorg.conf with content shown in resolution.
