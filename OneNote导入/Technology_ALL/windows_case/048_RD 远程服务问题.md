RD 远程服务问题

2019年1月23日

10:52

1. 客户安装注册完RD服务后发现远程过期时间还在提示。

![[Technology_ALL_windows_case_048_RD 远程服务问题_001.png]]

 

2. 解决方法：

・Sign in with a local administrator user on the RD Session Host server.

・Right click START button and select Run.

・[Enter following command and click \[OK\].]

              gpedit.msc

・In \"Local Group Policy Editor\" window, expand the following tree nodes.

              Local Computer Policy

                            Computer Configuration

                                          Administrative Templates

                                                        Windows Components

                                                                      Remote Desktop Services

                                                                                    Remote Desktop Session Host

                                                                                                  Licensing

・In right pane, double click the following registry entry.

              Set the Remote Desktop licensing mode

・[In \"Set the Remote Desktop licensing mode\" window, configure the licensing mode as below and click \[OK\].]

              \[ \] Not Configured

              \[X\] Enabled

              \[ \] Disabled

 

              Options:

                            Specify the licensing mode for the RD Session Host

                            server.

                            \[Per User\]             ////// You can also choose \"Per Device\" depends on the licensing mode customer purchased.

・In right pane, double click the following registry entry.

              Use the specified Remote Desktop license servers

・[In \"Use the specified Remote Desktop license servers\" window, specify the license server as below and click \[OK\].]

              \[ \] Not Configured

              \[X\] Enabled

              \[ \] Disabled

 

              Options:

                            License servers to use:

                            \[IP address or hostname of the license server\]  ////// You can specify multiple license servers by separating them with commas.

                            

                            Separate license server names with commas.

                            

                            Example: Server1,Server2.example.com,192.168.1.1

・Restart the computer and check whether the warning message pops up again.
