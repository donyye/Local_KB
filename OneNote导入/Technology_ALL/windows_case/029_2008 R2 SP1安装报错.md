Hi Team

 

版本16.04.07的OS driver package " important information"中有明确说明这个已知问题:

 

[http://www.dell.com/support/home/cn/zh/cnbsd1/Drivers/DriversDetails?driverId=9X5JD](http://www.dell.com/support/home/cn/zh/cnbsd1/Drivers/DriversDetails?driverId=9X5JD)

 

![[Technology_ALL_windows_case_029_2008 R2 SP1安装报错_001.jpg]]

原因是这个OS driver package里面有驱动用了SHA-2签名,而Windows Server 2008 R2 SP1 Image并不支持SHA-2,打上补丁KB3033929后可以支持.

 

 

所以解决方法有三种:

 

a、先将KB 3033929加入到Windows Server 2008 R2 SP1 Image里，再安装操作系统。

 

b、安装windows 2008后，重启后按F8禁用签名验证，进入系统后安装KB 3033929。

 

c、将OS drive pach版本降低到16.03.00,然后安装KB 3033929和最新驱动。

 

附：KB 3033929下载地址：

[https://www.microsoft.com/en-us/download/details.aspx?id=46083](https://www.microsoft.com/en-us/download/details.aspx?id=46083)
