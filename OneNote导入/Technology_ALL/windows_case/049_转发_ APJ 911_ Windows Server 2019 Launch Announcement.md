很高兴的通知大家Windows Server 2019 将在2月12日正式RTS。这次上市的包括14G所有系列服务器可选预装Windows Server 2019，以及针对渠道销售的ROK版本。

 

关于许可方式：

Windows Server 2019的授权方式和2016一样，按照物理core授权，同时客户还需要购买Windows Server 2019 CAL（客户端访问许可）

 

关于价格调整：

Windows Server 2019标准版和Windows Server 2019 CAL，都在原来2016基础上涨价10%，这个是微软2019全产品线涨价策略，所以open license和 OEM都受到影响。具体价格变化请查看Gii系统。

 

关于降级：

购买Windows Server 2019作为出厂安装选项的客户可以免费申请降级套件到Windows Server 2016。 必须在购买服务器时购买降级套件。 首次购买完成后，Dell EMC没有满足降级请求的流程。

如果客户需要降级到Windows Server 2012，建议购买Windows Server 2016和Windows Server 2012R2降级介质
