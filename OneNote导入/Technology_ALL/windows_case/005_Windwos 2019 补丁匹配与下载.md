Windwos 2019 补丁匹配与下载

2019年12月12日

11:04

Windwos 2019 （W2K19）最新补丁分为两个版本

 

Security Rollup只包含安全问题。Monthly Rollup既包含安全问题也包含其他OS的补丁。

 

17763 与 18362 可以从MPSReport里知道客户用的是哪个版本。

![[Technology_ALL_windows_case_005_Windwos 2019 补丁匹配与下载_001.png]]

 

 

Windows 10 and Windows Server 2019 update history

            Applies to: Windows 10, version 1809, Windows Server version 1809, Windows Server 2019, all versions

            <https://support.microsoft.com/en-us/help/4464619>

            Remark: OS Build 17763

 

Windows 10 update history

            Applies to: Windows 10, version 1903, Windows Server, version 1903

            <https://support.microsoft.com/en-us/help/4498140>

            Remark: OS Build 18362

============================

升级补丁时也需要先升级，先更新SSU，然后是LCU。

关于SSU，比如

<https://support.microsoft.com/en-us/help/4530715>

 

1. 当前最新的补丁（LCU）是 KB4530715

![[Technology_ALL_windows_case_005_Windwos 2019 补丁匹配与下载_002.png]]

 

2. 那它对应的SSU就是 BK4523204，在这个补丁的页面那里可以看到。

![[Technology_ALL_windows_case_005_Windwos 2019 补丁匹配与下载_003.png]]

 

 

3. 然后到补丁下载去下载这个两个补丁：

<https://www.catalog.update.microsoft.com/search.aspx?q=4523204>
