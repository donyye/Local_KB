Steps to collect MS Diagnostic Report

 

Microsoft Support Diagnostics link provided as below:

[https://home.diagnostics.support.microsoft.com/SelfHelp/?wa=wsignin1.0](https://home.diagnostics.support.microsoft.com/SelfHelp/?wa=wsignin1.0)

 

- from the Diagnostic Packages search for "Windows FailoverCluster Diagnostic" 

![[Technology_ALL_windows_case_055_MS Diagnostic Report 日志收集_001.png]]

 

- Click on "Create"  

![[Technology_ALL_windows_case_055_MS Diagnostic Report 日志收集_002.png]]

 

- The Support Key is unique which every report will have different code, hence the System will require have internet access 

![[Technology_ALL_windows_case_055_MS Diagnostic Report 日志收集_003.png]]

 

- Follow Instruction to run the report

![[Technology_ALL_windows_case_055_MS Diagnostic Report 日志收集_004.png]]

 

- Paste the Support Key to generate the report which require take sometimes 

![[Technology_ALL_windows_case_055_MS Diagnostic Report 日志收集_005.png]]

 

- Click Next 

![[Technology_ALL_windows_case_055_MS Diagnostic Report 日志收集_006.png]]

 

- Click on " This Computer"

![[Technology_ALL_windows_case_055_MS Diagnostic Report 日志收集_007.png]]

 

- The log gather estimate time will not less than 30 minutes  (depend on report file capacity as well as system performance) 
- Click "Review the Data being sent"  

![[Technology_ALL_windows_case_055_MS Diagnostic Report 日志收集_008.png]]

 

- Click "Next "

![[Technology_ALL_windows_case_055_MS Diagnostic Report 日志收集_009.png]]

 

- Click " Closed "

![[Technology_ALL_windows_case_055_MS Diagnostic Report 日志收集_010.png]]

 

 

File Output : C:/Users/xxx/AppData/Local/ElevatedDiagnostics/

 

已使用 OneNote 创建。
