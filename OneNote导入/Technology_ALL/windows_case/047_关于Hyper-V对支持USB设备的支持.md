关于Hyper-V对支持USB设备的支持

2018年11月16日

8:42

最近使用Windows Server 2008 R2提供的Hyper-V功能部署多台虚拟机，其中一台虚拟机需要使用USB加密狗，需要Hyper-V下的虚拟机支持USB加密狗。

经过查阅资料确认后并经过测试确认：

- Hyper-V不支持直接使用宿主机的USB接口和COM，不能把宿主机器上的USB设备和COM接口直接映射到虚拟机里面。
- 使用USB接口的移动硬盘设备，可以在父分区中脱机使用 USB 硬盘驱动器，然后通过 IDE 或 iSCSE 控制器将其安装到虚拟机中。如果使用此方法将硬盘驱动器安装到虚拟机中，应将驱动器视为\"内部\"硬盘驱动器，因此不能从物理硬件上拔下此驱动器。

VMware可以很好的支持USB设备，建议微软注意该问题并尽早提供解决方案
