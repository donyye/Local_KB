Case : 166967949\
\
问题是，客户购买的多语言版本的 windows 2022，然后客户想改成单语言版本，想知道 多语言版本的OEM是否可以激活单语言版本的？

 

在之前的确认中是不行的，到那时这个客户成功的激活了单语言版本的OEM 2022。

 

TS Chang, Donglin 描述：

这case 客户原来2022多语言OEM  给客户1个OEM 单语言的OS 安装完毕后，按照客户的回复，用原来的多语言key也激活成功了
