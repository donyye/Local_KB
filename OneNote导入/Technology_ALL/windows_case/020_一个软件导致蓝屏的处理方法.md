  Jane,

  这个CASE 我跟TAM之前有沟通，从收集到的DUMP看，属于Driver Fault issue, 相关的Driver module为afd.sys, 涉及应用为w3wp， 这两个模块与硬件没有直接关联，为系统socket连接程序和IIS 服务模块。我的建议如下：

   

  1.  收集Dset再次确认硬件是否完全正常
  2.  请用户通过Windows Update程序检查所有系统和网络以及IIS方面的patch尤其是critical 的，打上所有补丁以观后效
  3.  关闭目前该系统上的所有防火墙/杀毒软件类和非必要的网络相关的第三方程序
  4.  做完以上操作后仍然存在相同问题的话，请用户设置好full memory dump后，开启Driver Verifier对Winodws Driver和非Windows Driver做两次单独的verification，期间不要再设置任何的DNS指向动作，一旦蓝屏出现了等待Dump完成后发给我们检查。Driver verifier 的设置步骤如下：

  开启verifier的模式:

  在开始菜单中搜索verifier程序

  1.       Select - \"Create custom settings (for code developers)\"

  2.       Select - \"Select individual settings from a full list\"

  3.       Check the following boxes -

  -          Special Pool

  -          Pool Tracking

  -          Force IRQL Checking

  -          Deadlock Detection

  -          Security Checks (Windows 7 & 8)

  -          DDI compliance checking (Windows 8)

  -          Miscellaneous Checks

  4.       Select  - \"Select driver names from a list\"

  5.       Click on the \"Provider\" tab. This will sort all of the drivers by the provider.

  6.       Check EVERY box that is provided by Microsoft or non Microsoft Corporation.

  7.       Click on Finish.

  8.       Restart.

   

   

  关闭verifier的模式:

  重启进入安全模式 ,打开命令行，运行命令  verifier /reset\" 然后重启
