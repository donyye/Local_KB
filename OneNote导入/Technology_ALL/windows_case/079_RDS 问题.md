1. 先确认客户是否有购买 Remote Desktop license\
TS可以看出现，大概是这样 

1-pack of Windows Server 2022 Remote Desktop Services, Device

 

如果是 下面这种，是系统自带的，必须采购的，他不是 remote desktop license 的记录

5-pack of Windows Server 2019/2016 Device CALs (Standard or Datacenter)

 

如果客户没有购买 license，那么出现 60秒过期的提示，直接删除 DRS 服务就可以了。
