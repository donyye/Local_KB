To begin, click on the Windows start button and open the Settings window, shown as a gear icon in the image below.

![[Technology_ALL_windows_case_061_Windows Server 2016 多语言版本添加中文显示_001.png]]

Now open Time & Language

![[Technology_ALL_windows_case_061_Windows Server 2016 多语言版本添加中文显示_002.png]]

Then Region & Language

![[Technology_ALL_windows_case_061_Windows Server 2016 多语言版本添加中文显示_003.png]]

Click Add a language

![[Technology_ALL_windows_case_061_Windows Server 2016 多语言版本添加中文显示_004.png]]

And from the list displayed select the language you wish to use

![[Technology_ALL_windows_case_061_Windows Server 2016 多语言版本添加中文显示_005.png]]

Select the region or country if asked

![[Technology_ALL_windows_case_061_Windows Server 2016 多语言版本添加中文显示_006.png]]

After you select this, it should take to back to the Settings you were at earlier.

Click on the language you selected, then Options

![[Technology_ALL_windows_case_061_Windows Server 2016 多语言版本添加中文显示_007.png]]

Click Download language pack, and once it finishes click the back arrow button at the top left corner.

![[Technology_ALL_windows_case_061_Windows Server 2016 多语言版本添加中文显示_008.png]]

It should now say installed

![[Technology_ALL_windows_case_061_Windows Server 2016 多语言版本添加中文显示_009.png]]

Click the language again and then Set as Default

![[Technology_ALL_windows_case_061_Windows Server 2016 多语言版本添加中文显示_010.png]]

Close that Settings windows and select the correct keyboard input to use on the taskbar at the bottom right.

![[Technology_ALL_windows_case_061_Windows Server 2016 多语言版本添加中文显示_011.png]]

Now reboot the server to complete the configuration and enable the new language.

 

You should now see Windows using the language you have chosen.

![[Technology_ALL_windows_case_061_Windows Server 2016 多语言版本添加中文显示_012.png]]
