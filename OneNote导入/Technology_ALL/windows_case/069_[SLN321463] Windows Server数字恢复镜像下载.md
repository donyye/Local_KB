DESCRIPTION

Windows Server系统恢复镜像开始提供数字版本，如果销售下单的时候帮用户选择数字版恢复镜像，用户可使用该订单的所有权账户登录DDL注册并下载（也可以选择物理光盘+数字恢复镜像，具体的以实际订单为准）。

关于DDL以及DDL订单注册的问题，请参阅KB:[SLN322064](https://kb.dell.com/infocenter/index?page=content&id=SLN322064&viewlocale=zh_CN) ，步骤1-6

 

如何区分订单是否有包含数字版恢复镜像？

带有Digitally Fulfilled Recovery Image即有包含数字恢复镜像，请注意检查完整的SKU描述，确认具体的数字恢复镜像的操作系统版本。

![[Technology_ALL_windows_case_069_[SLN321463] Windows Server数字恢复镜像下载_001.jpg]]

 

如何从DDL中获取系统恢复镜像下载？

1. 请用户使用该订单所有权账户（管理员）登陆DDL，并点击历史订单后搜索订单号找到该订单，点击进入订单详情。

注意：确认订单注册状态和所有权信息，请通过SFDC Chat联络CTE。

 

![[Technology_ALL_windows_case_069_[SLN321463] Windows Server数字恢复镜像下载_002.jpg]]

2. 点击进入产品详情。

![[Technology_ALL_windows_case_069_[SLN321463] Windows Server数字恢复镜像下载_003.png]]

3.按照下图指导，找到下载按钮，点击即可下载。

![[Technology_ALL_windows_case_069_[SLN321463] Windows Server数字恢复镜像下载_004.png]]

注意：如遇到下载速度过慢，可尝试使用迅雷下载。将使用Chrome 登陆DDL并下载，从Chrome打开下载内容并复制下载地址，然后添加到本机中的迅雷下载中。
