这里提供一个微软原厂下载SQL server 2019 ISO的方法支持多种语言，具体使用场景大家可根据实际案例自行脑洞。

 

[https://www.microsoft.com/en-us/sql-server/sql-server-downloads](https://www.microsoft.com/en-us/sql-server/sql-server-downloads)

 

![[Technology_ALL_windows_case_066_FW_ SQL Server 2019 微软原厂ISO下载方法_001.png]]

 

点击Download free trial 之后，在弹窗中填写完公司信息后，会下载一个SQL2019-SSEI-Eval.exe

 

这个程序提供三种功能，也可以根据实际需要直接运行和安装在操作系统上，或者下载ISO镜像。

![[Technology_ALL_windows_case_066_FW_ SQL Server 2019 微软原厂ISO下载方法_002.png]]

 

以下载ISO为例，选download media, 选择完语言（有英文，简中，繁中等可选）以及保存路径之后，点Download可直接下载ISO文件。
