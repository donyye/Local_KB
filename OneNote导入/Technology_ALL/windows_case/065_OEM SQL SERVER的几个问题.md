Q&A：

OEM SQL Server 2017是否可以降级到SQL2008 R2？

答：可以

 

OEM SQL Server 2017的key是否属于Volume license?

答：不属于

 

SQL SERVER2008 R2是否可以安装在Windows server 2012 R2上，有什么条件，

答： 可以，满足SP2即可，其他情况参考下面KB：

                <https://support.microsoft.com/en-us/help/2681562/using-sql-server-in-windows-8-and-later-versions-of-windows-operating>

 

 

降级介质和KEY从哪里寻找？

答：有同时购买降级KEY和介质的，直接使用即可。如果没有同时购买降级介质和KEY，客户要么选择购买(是否能够单独购买请客户跟Sales确认)，要么只能自己想办法找了，TS无法提供。
