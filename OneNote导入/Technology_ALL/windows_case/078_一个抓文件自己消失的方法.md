首先确保我们能够抓住真正的问题； 我们需要在安装完成系统后第一次重新启动之前启用启动日志。

如何启用引导日志：

请从以下位置下载 procmon：

[[Process Monitor - Sysinternals \| Microsoft Learn \[learn.microsoft.com\]]](https://urldefense.com/v3/__https:/learn.microsoft.com/en-us/sysinternals/downloads/procmon__;!!LpKI!m_aCroEh3pblaTeC6ftSWnr6I_qwp0G89wZB62G4isCN6i1yf81svwPfp4ViPZts44Oar_SIUjWlXuIWvxqpww$)

在 procmon 文件夹中启动并使用命令行运行以下命令：

Procmon64 /enablebootlogging /runtime 300 à 运行5分钟，您需要根据启动时间更改它，一般我们需要总启动时间+2-3分钟启动日志

然后重新启动机器到正常模式

然后按步骤2检查catroot文件夹大小，再次双击procmon，会弹出一个命令，如果要保存启动日志，单击"是"，带有.pml文件，没有过滤器。

 

 

1. 步骤（审核CatRoot和CatRoot2文件夹）：

我们首先需要启用catroot和catroot2文件夹审计，步骤如下：

A. 以管理员帐户打开 CMD 并运行以下命令：secpol.msc

B. 进入高级审核策略配置-\>系统审核策略-\>对象访问-\>审核文件系统-\>勾选成功和失败

Go to Advanced Audit Policy Configuration-\>System Audit Policies-\>Object Access-\>Audit File System-\>Tick Success and Failure

C. 单击应用并确定。

然后打开文件浏览文件catroot文件夹和catroot2文件夹，右键单击鼠标并单击属性-\>安全-\>高级-\>审核-\>单击添加-\>键入每个人-\>确定-\>选择完全控制-\>确定

Then open the file explore file the catroot folder and catroot2 folder, right click the mouse and click properties-\>security-\>advanced-\>auditing -\>click on add-\>type on everyone-\>OK-\>select Full Control-\>OK

2. 步骤（使用脚本监控catroot文件夹大小）：上传已在我们的工作区中。

3. 步骤（启用procmon）：

当我们发现步骤2中catroot文件夹数量减少时，请启用procmon，并等待3-5分钟，在这3-5分钟内，我们需要再次运行步骤2脚本，并找到输出，我们需要 在 procmon 文件捕获期间，数量不断减少或减少。 然后停止 procmon 并将其重新保存为不带任何内容的 pml 文件
