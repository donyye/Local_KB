  Purpose

  要解决此问题，您必须在 ESXi 主机上应用 VMware 提供的修补程序。

  Resolution

  该问题在以下版本中已解决：

  - ESXi 6.0 GA，可从 [VMware Downloads](https://https/my.vmware.com/web/vmware/info/slug/datacenter_cloud_infrastructure/vmware_vsphere/6_0) 获取。
  - ESXi 5.5，Patch Release ESXi550-201410001 (2087358)。有关详细信息，请参见 [VMware Downloads](https://www.vmware.com/patchmgr/findPatchByReleaseName.portal)。\
    \
    下载时，请使用发行日期为 2015 年 10 月 15 日且内部版本号为 2143827 的修补程序。
  - ESXi 5.1 Update 2，下载地址为 [VMware Downloads](https://my.vmware.com/web/vmware/details?downloadGroup=VCL-VSP510-ESXI-51U2&productId=285)。
  - ESXi 5.0 Patch Release ESXi500-201401001。有关详细信息，请参见 [VMware Downloads](https://www.vmware.com/patchmgr/findPatchByReleaseName.portal)。\
    \
    下载时，请使用发行日期为 2014 年 1 月 23 日且内部版本号为 1489721 的修补程序。

  注意：更新 ESXi 主机版本后，确保立即更新 VMware Tools。

  要在不升级的情况下临时解决此问题，请使用以下方案之一：

  - 使用 VMXNET3 虚拟适配器并减少 E1000e 系列适配器的使用。有关添加或修改虚拟机的虚拟网络接口的详细信息，请参见 [vSphere Virtual Machine Administration Guide](http://pubs.vmware.com/vsphere-55/index.jsp?topic=%2Fcom.vmware.vsphere.vm_admin.doc%2FGUID-3719A0BE-4B4A-44FF-8A21-290950918FBD.html) 中的"更改 vSphere Web Client 中的虚拟网络适配器 (NIC) 配置"一节。 
  - 在使用 E1000e 适配器的虚拟机中，禁用 RSS 或者将客户机操作系统中的 RSS 多个 rx 队列配置为 1。
