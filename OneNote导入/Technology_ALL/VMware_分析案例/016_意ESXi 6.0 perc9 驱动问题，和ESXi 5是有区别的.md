  Question
  PERC9 -- What driver is needed to install on ESXi 6.0 running PERC9 FW 25.3.0.0016?

+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| Answer                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| For last several years, Dell PERC has been using "megaraid" drivers for PERC9 and earlier controllers for ESXi OS support.                                                                                                                                                                                                                                                                                                                                            |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| However, if you have installed PERC 9.2 firmware 25.3.0.0016 running ESXi 6.0, you need to install "lsi-mr3 version 6.606.12" driver, and NOT "megaraid" driver.                                                                                                                                                                                                                                                                                                                 |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| We did qualify PERC9 FW 25.3.0.0016 with ESXi 5.5 U1 and U2 using megaraid drivers. Please make sure to check the VMWare HCL listing for the driver version.                                                                                                                                                                                                                                                                                                                                                                                          |
