忘记ESXI密码-重置

2022年8月30日

11:03

 

<https://kb.vmware.com/s/article/68079?lang=zh_CN>

 

注意：主机配置文件是只有 VMware vSphere Enterprise Plus 许可证才提供的一项功能。有关详细信息，请参阅 [vSphere Host Profiles](https://docs.vmware.com/en/VMware-vSphere/6.7/com.vmware.vsphere.hostprofiles.doc/GUID-7500B48E-6353-4FCB-A03E-C0295E5ADD46.html)

不支持任何其他方法，重新安装 ESXi 主机是在 ESXi 上重置密码的唯一支持方法。请注意，此知识库不适用于由 vCenter 6.5/6.7 管理的 ESXI 6.0

 

1.登录到 vCenter Web Client

2.转到主页，然后从"操作和策略"部分中选择"主机配置文件"。

3.选择"从主机中提取配置文件"。

4.在"提取主机配置文件"菜单向导中，选择要更新密码的主机。

5.对主机配置文件进行命名，单击"下一步"，然后单击"完成"以完成主机配置文件模板的捕获。

\- 新的主机配置文件应显示在"主机配置文件对象"字段中。

 

6.右键单击新的主机配置文件，或使用"操作"菜单选择"编辑设置"

7.在"编辑主机配置文件"向导中，取消选中所有框。

8.使用搜索筛选器搜索 root

9.突出显示，然后选中 root 对应的复选框

10.可配置的窗口将显示 root 用户配置。

11.在"密码"子部分中，选择"固定的密码配置"

12.在此处填写新密码并进行确认，然后再继续。

13.仔细检查，确保所有其他不适用的框都没有选中标记，然后继续单击"完成"。

14.任务完成后，突出显示新的主机配置文件，从"操作"下拉菜单中选择"附加/分离主机和集群"，然后在向导中选择主机。

15.从"操作"菜单中，选择"检查主机合规性"。

16.  从"操作"菜单中选择"修复"

17.单击"检查主机合规性"。

18.从主机中移除主机配置文件。
