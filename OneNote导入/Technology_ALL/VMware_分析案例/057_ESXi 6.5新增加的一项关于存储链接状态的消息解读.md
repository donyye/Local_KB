2017-05-31T08:23:20.032Z info hostd\[ED80B70\] \[Originator@6876 sub=Libs\] LunImpl: IsAccessible = false, path state = 2, lun state 5 

 

Here are the available path states ordered 0 to 5 : 

PATH_STATE_ACTIVE

PATH_STATE_OFF

PATH_STATE_DEAD

PATH_STATE_STANDBY

PATH_STATE_DEVICE_CHANGED

PATH_STATE_UNKNOWN

The available LUN States are below, ordered 0 to 6 :

OK

Error

Off

Quiesced

Degraded

lostCommunication

timeout

So in our customer\'s case the path state was \"dead\" (2) and lun state was lost communication (5).

Caution : Please do not share these information with the customer as this is VMware proprietary information and internal to us only. Customer need not go by these numbers to determine the path & lun states. VMkernel log would clearly tell if the paths went dead and lun hit apd.
