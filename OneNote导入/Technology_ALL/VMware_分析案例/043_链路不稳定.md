  Hi Neil,

   

  从提供的日志看，客户并没有使用VSAN，而是 EQ。 目前存在的问题是存储链路不稳定，一直在频繁的切换和闪断，尤其是近期链路抖动非常频繁，这样会导致hostd进程消耗较大的开销来维护链路，从而使ESXi进入卡滞状态。

  ESXi端除部分virtual ISCSI配置需要调整外不存在其他问题，

  iscsi network中的物理网络部分是否为DELL设备，如果是的话，请协助客户开CASE检查下交换机的iscsi 部分设置和端口及Log是否存在问题，  

  存储端为EQ，同样请协助客户开个CASE检查存储设备的latency以及部署是否符合best practice要求。

   

   

  ESXi端问题和建议如下：

  1.  Virtual ISCSI network中，ISCSI01未做物理网卡绑定，这对于iscsi network不合规，需要调整为绑定到vmnic10 

  PortGroup Name        VLAN ID  Used Ports  Uplinks  

  VMHA                  0        0           vmnic6,vmnic10

  ISCSI02               0        1           vmnic6   

  ISCSI01               0        1           vmnic10,vmnic6

  1.  Iscsi network 绑定的网卡82599驱动版本太低，中间涉及的bugfix非常多，建议升级到4.4.1版本

  <https://my.vmware.com/web/vmware/details?downloadGroup=DT-ESXI55-INTEL-IXGBE-4.4.1&productId=353>

   

  1.  82599固件建议升级到以下版本

  [http://www.dell.com/support/home/us/en/19/Drivers/DriversDetails?driverId=6FD9P](http://www.dell.com/support/home/us/en/19/Drivers/DriversDetails?driverId=6FD9P)

  1.  建议客户后续将ESXi升级到5.5 U3
