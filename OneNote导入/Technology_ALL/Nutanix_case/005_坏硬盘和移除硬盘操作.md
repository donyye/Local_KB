  [1: Remove a Drive Using the Web Console](http://)

  Identify a Drive by LED Activity

  CAUTION: Hard disk drives (HDDs) and solid state drives (SSDs) SSDs are not hot-swappable. 

  This procedure is optional and not the recommended method for identifying a drive for removal or replacement.

  1.  Select the drive you want to check by viewing the LED activity.
  2.  Select Turn On LED.
  3.  View the LED activity on the drives.

  Drive LEDs follow the standard Dell™ flashing pattern.

  Remove a Drive

  1.  In the Web Console, select Home \> Hardware.

  ![[Technology_ALL_Nutanix_case_005_坏硬盘和移除硬盘操作_002.jpg]]

  1.  Select Diagram.

  A diagram of drives in each node is displayed. The following two images show Dell™ XC730xd nodes, one with 12 drives and the other with 24 drives.

  ![[Technology_ALL_Nutanix_case_005_坏硬盘和移除硬盘操作_003.jpg]]

   

  ![[Technology_ALL_Nutanix_case_005_坏硬盘和移除硬盘操作_004.jpg]]

  1.  Select the drive to be removed and click Remove Disk.

  ![[Technology_ALL_Nutanix_case_005_坏硬盘和移除硬盘操作_005.jpg]]

  1.  In the removal confirmation dialog box, click OK to begin the removal process.

  ![[Technology_ALL_Nutanix_case_005_坏硬盘和移除硬盘操作_006.jpg]]

  The Controller Virtual Machine (CVM) begins the removal process. The following image shows the Data_migration_initiated disk status, which is displayed until the removal process is complete. The subsequent two images show the progress of the removal.

  ![[Technology_ALL_Nutanix_case_005_坏硬盘和移除硬盘操作_007.jpg]]

   

  ![[Technology_ALL_Nutanix_case_005_坏硬盘和移除硬盘操作_008.jpg]]

   

  ![[Technology_ALL_Nutanix_case_005_坏硬盘和移除硬盘操作_009.jpg]]

  1.  When the removal process has completed, see the instructions on the [HDD and SSD (Data Drives)](http://prm.dell.com/content2/cninv000000000040678/GUID-9C0A1B74-BC4E-4AA2-848B-077545AB4FFE.html) page to physically remove the drive.

  Removed drives may be physically removed or repartitioned, and then added back in to the cluster.

  CAUTION: HDDs and SSDs are not hot-swappable.

  ![[Technology_ALL_Nutanix_case_005_坏硬盘和移除硬盘操作_010.jpg]]

   

   

   

  2: Complete a Drive Replacement

  CAUTION: Hard disk drives (HDDs) and solid state drives (SSDs) are not hot-swappable.

  1.  From the web console, click Hardware\>Diagram, and hover the mouse over the drive that was replaced to view the details.

  The drive indicator should not be red. Failure messages should not be displayed when the drive is selected.

  ![[Technology_ALL_Nutanix_case_005_坏硬盘和移除硬盘操作_011.jpg]]

  1.  If the drive label shows Unmounted Drive, click Repartition and Add.

  The following CAUTION message and the button are displayed only when the replacement drive contains data. The purpose is to prevent you from unintentionally using a drive that contains data.

  CAUTION: This action removes all data on the drive. If you are not certain that the correct replacement drive was inserted, do not repartition until you have confirmed that it contains no data that is needed.

  ![[Technology_ALL_Nutanix_case_005_坏硬盘和移除硬盘操作_012.jpg]]

  1.  On the Web console, click Summary \> Disk Details to verify that the disk was added to the original storage pool.

  ![[Technology_ALL_Nutanix_case_005_坏硬盘和移除硬盘操作_013.jpg]]

  If the cluster has only one storage pool, the disk is automatically added to that storage pool.

  1.  (Optional) If the drive was not added to the storage pool because more than one storage pool is in the cluster, then add the drive to the desired storage pool.
      1.  In the web console, select Storage from the drop-down main menu (upper left of screen), click the Table tab, and then click the Storage Pool tab. 

  ![[Technology_ALL_Nutanix_case_005_坏硬盘和移除硬盘操作_014.jpg]]

  1.  Select the target storage pool and then click Update.

  The Update Storage Pool window opens.

  1.  In the Capacity group, select the Use unallocated capacity check box to add the available unallocated capacity to this storage pool, and then click Save.
  2.  Click Hardware \> Diagram, select the drive, and confirm that it is in the correct storage pool.
