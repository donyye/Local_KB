| ​When creating clusters with more than 6 nodes, you may encounter timeout issues. To avoid this, it is recommended that clusters be created with 6 nodes or less. Additional nodes should be added (in groups of 6 or less) until the entire cluster is created.                                                                                                                                                                                                 |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| BIOS version 2.2.5 and iDRAC update 2.40.40.40 are available and should be used on all XC deployments (except XC6320 which has a different BIOS).                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| In general, the BIOS settings of XC nodes should be left at the default settings. The Default settings (as shipped from the factory or by clicking the default button in the BIOS setup) are optimized for XC deployments. One exception to this is the System Profile Setting. If customers anticipate periods of low activity, the default setting will allow the system to save energy. If customers do not anticipate periods of low activity, the performance setting can be chosen to prevent the system from slowing down while under light load. |
