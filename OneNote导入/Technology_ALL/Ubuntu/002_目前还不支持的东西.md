Current Version

 

Ubuntu Server LTS v16.04.3 is certified on 14G servers but there are some drivers missing in this version as detailed in the table below. At the time of writing NVDIMM and NVMe had not been validated on this release of Ubuntu. Support for these devices is expected in the next release of Ubuntu 16.04.4 due in Q2 FY19.

 

+-----------------------------------+------------------------------------+
| Ubuntu Server Version             | Comments                           |
+-----------------------------------+------------------------------------+
| LTS 16.04.3                       | No support for PERC10: H740P, H840 |
|                                   |                                    |
|                                   | No support for Qlogic QL41xxx NICs |
+-----------------------------------+------------------------------------+
