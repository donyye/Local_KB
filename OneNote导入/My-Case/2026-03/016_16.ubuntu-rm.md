1. 问题

Windows RDP 无法访问 ubuntu远程桌面。

问题出现在 3月20号下午1点左右到3月21日上午10点左右。

重启 ubuntu 系统后可以恢复。

 

 

2. 原因分析

Windows 客户端通过远程桌面连接 Ubuntu 有出现关于 XRDP 服务在处理 RDP TLS时无法读取 key.pem 文件，导致了安全连接初始化失败。

本次问题很可能是 XRDP 服务导致了远程访问失败，属于服务配置权限问题，而重启系统后 xrdp 服务重新给了正确的权限。

目前并没有太多的证据指向为什么权限会改变的原因，有可能是系统更新或是xrdp自身的问题，如果需要进一步的分析，建议找到 ubuntu vendor进行。

。

 

如果后续有相同问出现，可以尝试重启一下 xrdp 服务，看是否能解决。

sudo systemctl restart xrdp xrdp-sesman

 

如果频繁出现可能需要 ubuntu 检查 xrdp 是否有bug或其它问题。
