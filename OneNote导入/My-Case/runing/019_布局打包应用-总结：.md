布局打包应用-总结：

 

使用模板通过参数化部署工作负载。​

 

使用 oc create -f 命令，​将模板文件上传到项目。​

 

使用 oc process 命令和 oc apply -f - 命令将模板资源部署到 Kubernetes 集群。​

 

提供参数以使用 oc 命令的 -p 或 --param-file 参数自定义模板。​

 

使用 helm show chart chart-reference 和 helm show values chart-reference 命令查看 Helm 图表。​

 

使用 helm install release-name chart-reference 命令为图表创建发行版。​

 

使用 helm list 命令检查发行版。​

 

使用 helm history release-name 命令可查看发行版的历史记录。​

 

使用 helm repo add repo-name repo-url 命令，​将 Helm 存储库添加到 ~/.config/helm/repositories.yaml 配置文件。​

 

使用 helm search repo 命令，​在 ~/.config/helm/repositories.yaml 配置文件中搜索存储库。
