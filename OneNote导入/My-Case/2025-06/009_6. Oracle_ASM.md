---------------------------------------\
Analyzing:

Customer feedback on the system has a large number of blk_update_request: I/O error.

Solution:

Initial log analysis, the customer environment when ASM, the system recorded multipath has a large number of access IO timeout and then recovered, repeated this process.\
Suspect this may have something to do with the access timeout settings of some SAM or the hardware version and links, etc.

Next step:

Have the customer provide logs from another machine.

====== 3 =====

Resolution：

L1反馈：客户使用TCP 协议， 不用之前的协议（是啥我也不清楚）。目前测试看没有啥问题。
 

Root Cause: 

Oracle ASM 它是 oracle 一个关闭存储方面的集群，目前客户所报的问题是连接的多路径会不停的掉路径，然后是机器和机器对连接，没走交换机。后来客户说把它改成 TCP 协议后就可以了。
