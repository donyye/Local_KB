TCP Segmentation Offload (TSO): TSO 允许网络适配器卸载 TCP 分段的任务，即将大块的数据分割成适当大小的 TCP 段。这个任务通常由主机 CPU 完成，但通过启用 TSO，可以将这部分工作卸载到网络适配器上，从而提高网络性能。

 

Generic Segmentation Offload (GSO): 类似于 TSO，GSO 允许网络适配器卸载协议无关的数据分段任务。它允许适配器处理大块数据的分段，而不仅仅是 TCP 数据。

 

 

 

 

ping -M do 192.168.11.36 -s 1400 -4

 

这个命令是使用 ping 工具，通过 -M 选项设置 DF (Don't Fragment) 标志，-s 选项设置数据包大小，-4 选项指定使用 IPv4 地址。具体解释如下：

- -M do: 设置 DF (Don't Fragment) 标志，该标志告诉中间网络设备不要对 ICMP 包进行分片。如果数据包太大，无法在网络上的某个地方进行分片，那么该数据包将被丢弃，并返回相应的 ICMP 错误消息。
- -s 1400: 设置 ICMP 包的大小为 1400 字节。这个值包括 ICMP 头和数据。请注意，这个大小应小于网络路径上所有设备的 MTU（最大传输单元）以确保不会被分片。默认情况下，Ethernet 的 MTU 为 1500 字节，所以选择 1400 是为了给 ICMP 头留出足够的空间。
- -4: 强制使用 IPv4 地址。

此命令的目的通常是测试网络路径上是否允许指定大小的不分片 ICMP 包通过。
