IM最后总结：

 

一、基础信息

- GPU 型号：NVIDIA L20 ×4
- GPU 固件版本：95.02.7C.00.04
- 驱动版本：570.124.06
- CUDA 版本：12.8（最早版本为 12.6，客户不确定升级时间）
- 操作系统：Ubuntu 22.04.5 LTS
- 内核版本：5.15.0-138-generic
- 硬件平台：Dell R760XA
- BIOS 版本：v2.4.4（2024-09-27）
- iDRAC & LC 版本：7.10.90.00

 

二、问题概述

- 客户部署情况：约有 40 台服务器配置 NVIDIA L20 GPU，操作系统为 Ubuntu 22.04.5 LTS，CUDA  版本为 12.8。
- 异常现象：
  - 每月随机约 2--3 台服务器出现 GPU 异常；
  - 系统日志中报错如下：

NVRM: GPU 0000:61:00.0: RmInitAdapter failed! (0x62:0x65:1860)

NVRM: GPU 0000:61:00.0: rm_init_adapter failed, device minor number 1

- 某块 GPU 无法识别，需重启系统后恢复；
- 同时伴随大量 syslog/debug 日志，如：

NVRM: gpuHandleSanityCheckRegReadError_GM107: Possible bad register read: addr: 0x110100, regvalue: 0xbadf5620, error code: Unknown SYS_PRI_ERROR_CODE

- 启用 GPU Persistence-Mode后，目前暂未发现再次出现问题；

 

三、问题初步判断与关联信息

- 初步排查认为该问题可能涉及以下多个维度：
  - Persistence-Mode 有效，表明可能与空闲状态下 GPU 电源管理相关，涉及驱动与内核交互机制。
  - OS兼容性：Ubuntu 22.04 不在 Dell 官方对 R760XA 支持列表中（推荐为 Ubuntu 24.04），可能存在兼容性风险。
    - 参考文档：[Ubuntu LTS Support Matrix for Dell Platforms](https://linux.dell.com/files/supportmatrix/Ubuntu_LTS_Support_Matrix.pdf)
  - 内核/驱动 Bug：日志中出现 gpuHandleSanityCheckRegReadError_GM107  报错，从硬件日志未发现故障迹象；
  - Red Hat 社区中存在类似案例，指向为内核层 bug，可能导致 GPU 初始化失败。不过目前是ubuntu系统，所以仅作参考。
  - 从提供的新系统日志里看，也没有看到很明确的说具体什么方面的问题。查询Nvidia论坛，有类似说运行多个CUDA程序时可能会出现这种问题。
    - [https://forums.developer.nvidia.com/t/gpu-in-a-bad-state-only-power-cycle-helps/21673](https://forums.developer.nvidia.com/t/gpu-in-a-bad-state-only-power-cycle-helps/21673)

 

四、建议方案

1.  启用 GPU Persistence-Mode继续观察。
2.  确保 BIOS  至最新版本，并在 BIOS 设置中将 System Profile 调整为 Performance  模式，排除主板对设备电源调度影响；
3.  若业务允许，建议未来过渡到 Ubuntu 24.04，以获得R760XA 的系统兼容性支持，如在新版本下今后依旧问题，在收集相关日志给我们分析。
4.  有条件，将 NVIDIA  驱动 + CUDA 升级至最新版本，如 CUDA 12.9；
