系统盘符的错乱这个并不是硬件上的问题，它是Linux kernel 一贯以来的命名规则导致，基于对设备的枚举而赋予设备名字，大概的过程是 Non-RAID  --\> Enclosure/Slot position order --\> Virtual Drives ，相同设备命名也会因为一些问题导致命名经常改变。

 

Redhat KB 有对这方面的详细说明：

<https://access.redhat.com/solutions/3962551>

 

其中KB里也提到虽然有些方面可以修改，但是任然无法保证所有设备名称一致。

 

Issue

- At each boot, the disk letter will change at some rate, e.g. the same hard drive can be detected as /dev/sda at one reboot, and /dev/sdc at the next reboot.
- How to make sure the same drive is identified to /dev/sdX at each reboot?

 

Resolution

- Except for udev rule or using provided persistent /dev/disk/by-id device names mentioned above, users can modify kernel boot parameters in RHEL 6, 7, and 8 by appending "scsi_mod.scan=sync" in the /etc/sysconfig/grub file to get more consistent disk letter.
  - This feature will still not guarantee consistent device names in all cases.
  - This option should be used with caution as it slows down disk discovery procedure and thus whole boot process.
  - See [Diagnostic Steps](https://access.redhat.com/solutions/3962551#diagnostics) for additional details.
- As the path-based addresses (e.g. /dev/sdX) are [not persistent per kernel design](https://access.redhat.com/solutions/3962551#root_cause), Red Hat recommends to use one of the following methods to access the disk devices.
  - [DM-Mmultipath](https://access.redhat.com/solutions/44389#multipath) ; WWID based persistent names
  - [LVM Logical Volumes](https://access.redhat.com/solutions/44389#LVM) ; UUID based persistent names
  - [Kernel Supplied Persistent Names](https://access.redhat.com/solutions/44389#persistent_names)
    - ["What persistent device names are provided by the kernel in Red Hat Enterprise Linux 7, 8 or 9?"](https://access.redhat.com/solutions/5757361)
  - [User Created Custom Names via udev rules](https://access.redhat.com/solutions/44389#udev_rules)
    - ["How are custom persistent names assigned for SCSI devices using udev in Red Hat Enterprise Linux 7 and later kernels?"](https://access.redhat.com/solutions/2975361)
    - ["How to create custom persistent names for SCSI devices in Red Hat Enterprise Linux 4, 5 and 6?"](https://access.redhat.com/solutions/4201)
