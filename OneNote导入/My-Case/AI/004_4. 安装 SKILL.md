4. 安装 SKILL

 

安装gethub指令：

npm i -g clawhub

 

安装例子：

比如你在官网找到了一个 skill 如下：

<https://clawhub.ai/Jacky1n7/openclaw-tavily-search>

 

复制 openclaw-tavily-search ，然后使用下面命令进行安装：

dell@SY10125:/mnt/c/WINDOWS/system32$ clawhub install "openclaw-tavily-search"

✔ OK. Installed openclaw-tavily-search -\> /home/dell/.openclaw/workspace/skills/openclaw-tavily-search

 

或者你可以先 search 一下看看有那些再安装：

dell@SY10125:/mnt/c/WINDOWS/system32$ clawhub search tavily
