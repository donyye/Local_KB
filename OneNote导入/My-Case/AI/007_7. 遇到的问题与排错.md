7. 遇到的问题与排错

1. window：解决安装了 clawhub 后还是无法使用的问题

 

问题：

dell@SY10125:/mnt/c/WINDOWS/system32$ npm i -g clawhub

 

added 34 packages in 11s

 

20 packages are looking for funding

  run `npm fund` for details

dell@SY10125:/mnt/c/WINDOWS/system32$ clawhub install "tavily+web+search"

clawhub: command not found

 

测试：

dell@SY10125:/mnt/c/WINDOWS/system32$ clawhub --version

clawhub: command not found

dell@SY10125:/mnt/c/WINDOWS/system32$

dell@SY10125:/mnt/c/WINDOWS/system32$ npm list -g --depth=0

/home/dell/.npm-global/lib

├── clawhub@0.8.0

└── openclaw@2026.3.12

 

dell@SY10125:/mnt/c/WINDOWS/system32$ npm bin -g

Unknown command: "bin"

 

To see a list of supported npm commands, run:

  npm help

dell@SY10125:/mnt/c/WINDOWS/system32$ echo $PATH

/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin:/usr/games:/usr/local/games:/usr/lib/wsl/lib:/mnt/c/WINDOWS/system32:/mnt/c/WINDOWS:/mnt/c/WINDOWS/System32/Wbem:/mnt/c/WINDOWS/System32/WindowsPowerShell/v1.0/:/mnt/c/WINDOWS/System32/OpenSSH/:/mnt/c/Program Files/dotnet/:/mnt/c/Users/DELL/AppData/Local/Microsoft/WindowsApps

这里说明 clawhub 已经按照，但是并没有在命令执行路径里。

 

解决永久：

dell@SY10125:/mnt/c/WINDOWS/system32$ echo 'export PATH=$HOME/.npm-global/bin:$PATH' \>\> ~/.bashrc

dell@SY10125:/mnt/c/WINDOWS/system32$ source ~/.bashrc
