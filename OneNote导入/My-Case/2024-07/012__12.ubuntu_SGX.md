Detail Symptom Descriptions(故障现象): linux系统安装SGX驱动后，无法开启SGX功能;

Troubleshooting Steps(详细诊断步骤):

客户服务器底层是Linux定制开发后的封装系统，在底层Linux系统上装了vmware vsphere这个虚拟机软件，

软件里运行了两个ubuntu 20.04的系统。

客户在ubuntu系统安装SGX驱动后，提示不支持SGX功能。;

Current status(当前状态和要求): 需要系统开启SGX的功能，目前客户在与客户的老师确认是否可以远程;

====== 2 =====

The TS feedback case can be closed.\
----------------------------\
By remotely helping the customer to debug SGX, it can be successfully turned on. Under observation.\
----------------------------\
Analyzing:

Feedback on ubuntu with SGX turned on.

Solution:

SGX needs to be enabled in the BIOS. Passed LKB 000189825b check.

Then it needs to be checked at the system using the following command:

cpuid --one-cpu |grep -i sgx

Next step:

Waiting for update.

====== 3 =====

Resolution：

客户R960安装是的ESXI 7.0u2 系统，然后上面跑 ubuntu VM , 想在上面开启 SGX功能。

1.需要在BIOS上设置，开启 SGX。有LKB提示如何开启。

2.需要在VM上开启，在编辑VM的安全设备上。

3.在VM系统里可以通过命令确认是否开启。
