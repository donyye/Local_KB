关于此问题的KB：

System log shows error - "SMART Failure: FIRMWARE IMPENDING FAILURE DATA ERROR RATE TOO HIGH"

[https://access.redhat.com/solutions/3642382](https://access.redhat.com/solutions/3642382)

Resolution

- Engage the hardware vendor.
- Run a full disk/hardware diagnostic on the server and replace the disks if they reported a disk failure or any issue.

Root Cause

- SMART stands for Self-Monitoring, Analysis and Reporting Technology, system built into most ATA/SATA and SCSI/SAS hard drives and solid-state drives.
- SMART disk drives internally monitor their own health and performance. Occasionally, the disk itself provides advance warning that an imminent failure might occur.
- The "FIRMWARE IMPENDING FAILURE DATA ERROR RATE TOO HIGH" indicates a hardware error and the affected device should be checked.

 

从整体来看，"SMART Failure: FIRMWARE IMPENDING FAILURE DATA ERROR RATE TOO HIGH" 出现是一个漫长的累计的过程，到一定程度可能会导致系统不稳定或卡死。

因为没有更多的信息可以证实具体原因，猜测 2SBNM03 的卡死可能就与此问题有关。
