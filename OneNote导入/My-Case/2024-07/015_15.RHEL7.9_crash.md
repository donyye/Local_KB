[[RHEL 7.7] PowerPC Little Endian node was panicked in kmem_cache_alloc() due to freelist pointer corruption]

 

Environment

Red Hat Enterprise Linux 7.8 and below

IBM Elastic Storage System version 5.3.5.2-1.0.492

Issue

Kernel panic occurred due to corrupted free list pointer by kmem_cache_alloc()

Resolution

For RHEL 7:

. Issue was fixed in kernel-3.10.0-1160.11.1.el7.ppc64le via BZ-1873189 from RHSA-2020:5437.

 

For RHEL 7.7.z:

 

. Issue was fixed in kernel-3.10.0-1062.40.1.el7.x86_64 via BZ-1893807 from RHSA-2020:5206.

 

. Upgrade the kernel to latest available kernel of RHEL 7.9 for mitigating the issue.

 

Root Cause

There appears to be a potential race between the creation of a sysfs object and its deletion in the OPAL error log handling code in the kernel.

We could end up in a scenario where multiple error log interrupts are handled simultaneously which could lead to this race and cause corruption in the free list pointer.
