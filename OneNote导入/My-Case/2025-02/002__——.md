  2. 确认容器状态及退出原因

  \
  查看容器状态和退出码：

   

  \<BASH\>

  docker ps -a | grep -E "container1|container2"[  # ]替换为实际容器名

  - 关键字段：
  - STATUS：若为 Exited (...) ，需检查退出码。
  - Exited (1) 或非零值表明容器启动失败。

   

   

   

  3. 分析容器日志

   

  docker logs container1
  docker logs container2
