----Remark----

 

 

比如原来本地yum的配置文件是 local.repo 文件，redhat.repo 是系统添加订阅后生成的新的yum文件。

如下例子：

[root@rhel9 ~]# ll /etc/yum.repos.d/

total 192

-rw-r--r--. 1 root root 184964 Jan 13 10:09 local.repo

-rw-r--r--. 1 root root     86 May 19  2023 redhat.repo

 

可以在 /etc/yum.repos.d/ 新建一个 backup 文件夹，然后吧redhat.repo 文件移动到backup文件夹里。

如例子：

# mkdir /etc/yum.repos.d/backup

# mv /etc/yum.repos.d/redhat.repo  /etc/yum.repos.d/backup

如果有多个就移动多个，只保留本地yum 配置

 

然后清除一下yum缓存和建立新缓存, 就可以使用回原来本地的yum源。

# yum clean all

# yum repolist

 

如果你想多个yum 源一起使用，在安装软件的时候也可以指定某个源来提供安装。

比如下面例子，屏蔽了所有yum源，只使用 local 的本地yum源来安装 httpd 服务。

# yum --disablerepo=\* --enablerepo=local install httpd
