第02题：配置您的系统以使用默认存储库

2024年12月24日

15:05

\# 这个设置主要是为了编译时可以对齐

\[greg@control ansible\]\$ echo set nu ts=2 et cuc sw=2 autoindent \> \~/.vimrc

 

\# 确认各个受管节点all

\[greg@control ansible\]\$ ansible-inventory \--graph

 

查模块名称[  \--\> ]这里开多一个新的窗口

\[greg@control ansible\]\$ ansible-doc -l \| grep yum

 

\# 查模块⽤法。==/EX==，在⼿册中搜索 EXAMPLE 示例

\[greg@control ansible\]\$ ansible-doc yum_repository

 

\# 编译剧本 \[主要格式[\]]

\[greg@control ansible\]\$ vim /home/greg/ansible/yum_repo.yml

\-\--

\- name: repository    

[  hosts: all              \#]对所有主机

  tasks:

[  - ansible.builtin.yum_repository:                \#]这个是集合的全称，这样写比较规范，或者写 yum_repository 也行。

      name: EX294_BASE

  description: \"EX294 base software\"

      file: EX294_BASE

      baseurl: <http://content/rhel9.0/x86_64/dvd/BaseOS>

      gpgcheck: yes

      gpgkey: <http://content/rhel9.0/x86_64/dvd/RPM-GPG-KEY-redhat-release>

      enabled: yes

  

  - ansible.builtin.yum_repository:

      name: EX294_STREAM

      description: \"EX294 stream software\"

      file: EX294_STREAM

      baseurl: <http://content/rhel9.0/x86_64/dvd/AppStream>

      gpgcheck: yes

      gpgkey: <http://content/rhel9.0/x86_64/dvd/RPM-GPG-KEY-redhat-release>

      enabled: yes

 

\# 运行剧本

\[greg@control ansible\]\$ ansible-navigator run yum_repo.yml -m stdout

(Ansible新的剧本运行方式，必须做第一题的44-47行命令)

 

\# 验证：验证所有节点，若软件安装完毕，证明配置是否成功，按照一下包测试。

\[greg@control ansible\]\$ ansible all -a \'yum repoinfo\'

\[greg@control ansible\]\$ ansible all -a \'yum -y install ftp\'

 

\# 检查一下，所有机器是否有按照了 ftp 这个包。

\[greg@control ansible\]\$ ansible all -a \'rpm -q ftp\'
