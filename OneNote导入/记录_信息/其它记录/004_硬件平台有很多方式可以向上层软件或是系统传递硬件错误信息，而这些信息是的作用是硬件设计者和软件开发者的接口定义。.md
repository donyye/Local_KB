硬件平台有很多方式可以向上层软件或是系统传递硬件错误信息，而这些信息是的作用是硬件设计者和软件开发者的接口定义。

 

所以就有了APEI (Advanced Platform Error Interfaces) 高级平台错误接口

它的结构简单来说有4张表：

BOOT Error Record Table (BERT)[  ]引导错误记录表

Error Record Serialization Table (ERST)[  ]错误记录序列化表

Error Injection Table (EINJ)[   ]错误注入表

Hardware Error Source Table (HEST)[  ]硬件错误源表

\--\>在 HEST 中定义了很多硬件相关的错误源和错误类型。如 MCE、PCI-E、GHES 等等。

The messages are results of an hardware issue, and is based on GHES (Generic Hardware Error Source) reported by hardware/firmware thorough APEI (ACPI Platform Error Interface). The messages can be disabled with ghes.disable=1 option.
