analysis:

usb dongle can\'t use.

solution:

对ESXI而言，如果做USB直通，添加USB控制器给到对应的虚拟机，然后添加USB设备即可；

 

从测试测试可知，通用的USB设备直通并无问题，表明ESXI层面的直通和用户的配置无误；

 

仅类似加密狗相关设备存在问题，用户需与加密狗设备厂商确认其是否支持USB直通等相关使用场景；

 

同时，ESXI不支持的直通设备说明如下，请注意如下信息：

 

<https://kb.vmware.com/s/article/1021345?lang=en_us>

 

The devices not in the following list are available for passthrough including USB storage devices, USB dongle devices etc.

• USB devices such as mice and keyboards that have a bootable HID interface.

• USB devices such as real time video cameras and audio devices that use isochronous data transfers.

• USB devices on which an ESXi host is installed. For more information, see VMware support for USB/SD devices used for installing VMware ESXi (1010574).

• USB CCID (chip/smart card interface devices). To enable passthrough for USB smart card reader, see, Unable to passthrough a USB smart card reader to a guest operating system in ESXi version 6.x and later (55789).

• USB hub.

大多数加密狗设备都包含CCID/HID支持或接口，这些是无法作为直通设备存在的。
