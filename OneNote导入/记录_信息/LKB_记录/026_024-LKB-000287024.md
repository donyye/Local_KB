Title:

PowerEdge: RHEL9.4 error message \"Hardware error from APEI Generic Hardware Error Source: 4\"

 

Summanry: 

This article gives the solution of RHEL9.4 error message \"Hardware error from APEI Generic Hardware Error Source: 4\".

 

Symptoms:

The following error occurs in the TSR System Event Log:

A fatal error was detected on a component at bus 2 device 0 function 0.

 

dmesg has the following error:

\[Hardware Error\]: Hardware error from APEI Generic Hardware Error Source: 4

 

Cause:

N/A

 

Resolution:

Error seen on TSR:

![[记录_信息_LKB_记录_026_024-LKB-000287024_001.png]]

\
 

When the server is running the Red Hat Enterprise Linux 9.3 kernel (5.14.0-362.8.1.el9_3) or later, iDRAC reports the following error:

A fatal error was detected on a component at bus 2 device 0 function 0

 

 

Also in the system log, the kernel reports the following error:

\[[    0.775630\] \[Hardware Error\]: Hardware error from APEI Generic Hardware Error Source: 4\
\[    0.775634\] \[Hardware Error\]: It has been corrected by h/w and requires no further action\
\[    0.775636\] \[Hardware Error\]: event severity: corrected\
\[    0.775639\] \[Hardware Error\]:  Error 0, type: corrected\
\[    0.775643\] \[Hardware Error\]:   section_type: PCIe error\
\[    0.775645\] \[Hardware Error\]:   port_type: 7, PCIe to PCI/PCI-X bridge\
\[    0.775648\] \[Hardware Error\]:   version: 3.0\
\[    0.775651\] \[Hardware Error\]:   command: 0x0007, status: 0x0010\
\[    0.775655\] \[Hardware Error\]:   device_id: 0000:02:00.0\
\[    0.775659\] \[Hardware Error\]:   slot: 0\
\[    0.775661\] \[Hardware Error\]:   secondary_bus: 0x03\
\[    0.775663\] \[Hardware Error\]:   vendor_id: 0x1556, device_id: 0xbe00\
\[    0.775666\] \[Hardware Error\]:   class_code: 060400\
\[    0.775669\] \[Hardware Error\]:   bridge: secondary_status: 0x2000, control: 0x001b]

 

The only known workaround at this time is to downgrade to the Red Hat Enterprise Linux 9.2 kernel (5.14.0-284.11.1.el9_2 and later).

 

The error persists if the server is booted with a kernel version lower than Red Hat Enterprise Linux 9.3 (5.14.0-362.8.1.el9_3).

 

If idrac is still reporting RHEL9.4 kernel fatal errors, but dmesg is not reporting any Hardware error from APEI Generic Hardware Error Source errors, then as a workaround "printk_no_perconsole_kthreads" using the kernel parameter to boot will help and no idrac fatal errors will be seen after that. This parameter will work with kernel-5.14.0-427.18.1.el9_4.x86_64.
