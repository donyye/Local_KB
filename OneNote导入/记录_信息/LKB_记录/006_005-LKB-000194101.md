LKB-000194101

 

How to Install VMware vSphere ESXi7.0 Drivers

1. 下载驱动程序

下载完成后的文件名字 Broadcom-ELX-lpfc_12.8.511.0-1OEM.700.1.0.15843807_18018667-package.zip

这个文件需要先解压，得到一个 Broadcom-ELX-lpfc_12.8.511.0-1OEM.700.1.0.15843807_18018667.zip 文件。

 

![[记录_信息_LKB_记录_006_005-LKB-000194101_001.png]]

 

 

2. 查看当前驱动lpfc 的版本 

\[root@localhost:\~\] esxcli software vib list \|grep lpfc

lpfc                           12.8.298.3-1vmw.702.0.0.17867351     VMW     VMwareCertified   2021-07-23

 

3. 把下载解压的文件上传到ESXI系统里面的/tmp目录

如下图

 

![[记录_信息_LKB_记录_006_005-LKB-000194101_002.png]]

 

 

4. ESXI进入维护模式

在进入维护模式前需要把所有vm都迁移或是关机。

esxcli system maintenanceMode set \--enable yes[  \--]进入维护默认

esxcli system maintenanceMode set \--enable no[  \--]退出维护模式。驱动安装完成后再运行。

esxcli system maintenanceMode get \--检查目前是什么状态

如果是Disabled说明不在维护模式里，如果是Enabled说明已进入维护模式。

 

5. 安装驱动

esxcli software vib install -d /tmp/Broadcom-ELX-lpfc_12.8.511.0-1OEM.700.1.0.15843807_18018667.zip

 

![[记录_信息_LKB_记录_006_005-LKB-000194101_003.png]]

 

 

更新完成后需要重启ESXI

重启完成后使用命令查看lpfc版本

 

![[记录_信息_LKB_记录_006_005-LKB-000194101_004.png]]

 

可以看到已经更新。

 

6. 退出维护模式

esxcli system maintenanceMode set \--enable no
