Title:

PowerEdge: RHEL9.5 configuring cpu isolation failed.

 

Summanry: 

This article gives the solution of RHEL9.5, Failed to configure cpu isolation.

 

Symptoms:

Adding isolcpus=4,5,6,7,8,9 option to RHEL9.5 kernel option does not take effect, resulting in failure to isolate cpu.

 

Cause:

The grub command has changed since RHEL 9.3

 

\# grub2-mkconfig -o /boot/grub2/grub.cfg \--update-bls-cmdline

\
[https://docs.redhat.com/en/documentation/red_hat_enterprise_linux/9/html/9.3_release_notes/new-features#new-features-boot-loader](https://docs.redhat.com/en/documentation/red_hat_enterprise_linux/9/html/9.3_release_notes/new-features#new-features-boot-loader)

 

Resolution:

 

\# cat /etc/default/grub

GRUB_TIMEOUT=5

GRUB_DISTRIBUTOR=\"\$(sed \'s, release .\*\$,,g\' /etc/system-release)\"

GRUB_DEFAULT=saved

GRUB_DISABLE_SUBMENU=true

GRUB_TERMINAL_OUTPUT=\"console\"

GRUB_CMDLINE_LINUX=\"crashkernel=1G-4G:192M,4G-64G:256M,64G-:512M resume=/dev/mapper/rhel-swap rd.lvm.lv=rhel/root rd.lvm.lv=rhel/swap isolcpus=4,5,6,7,8,9 rhgb quiet\"

GRUB_DISABLE_RECOVERY=\"true\"

GRUB_ENABLE_BLSCFG=true

 

\# grub2-mkconfig -o /boot/grub2/grub.cfg \--update-bls-cmdline

 

Reboot OS

 

\# cat /proc/cmdline

BOOT_IMAGE=(hd2,gpt2)/vmlinuz-5.14.0-503.11.1.el9_5.x86_64 root=/dev/mapper/rhel-root ro crashkernel=1G-4G:192M,4G-64G:256M,64G-:512M resume=/dev/mapper/rhel-swap rd.lvm.lv=rhel/root rd.lvm.lv=rhel/swap isolcpus=4,5,6,7,8,9 rhgb quiet
