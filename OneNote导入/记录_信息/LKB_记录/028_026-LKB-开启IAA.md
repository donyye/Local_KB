Title:

PowerEdge: Ubuntu 22.04 Cannot enable Intel CPU IAA

 

Summanry: 

This article gives the solution of Ubuntu 22.0 configure intel_iommu=on,sm_on still can\'t turn on Intel CPU  IAA.

 

Symptoms:

Ubuntu 22.04 After configuring "intel_iommu=on,sm_on", I still can\'t turn on CPU IAA using dmesg.

\# dmesg \|grep -i \'idxd\'

\[    6.184973\] idxd 0000:75:01.0: Unable to turn on user SVA feature.

\[    6.208009\] idxd 0000:75:01.0: Intel(R) Accelerator Device (v100)

 

 

 

\[    6.208366\] idxd 0000:f2:01.0: Unable to turn on user SVA feature.

\[    6.232842\] idxd 0000:f2:01.0: Intel(R) Accelerator Device (v100)

 

 

Cause:

N/A

 

Resolution:

Try adding the no5lvl parameter to the kernel again.

\# vim /etc/default/grub

GRUB_DEFAULT=0

GRUB_TIMEOUT_STYLE=hidden

GRUB_TIMEOUT=0

GRUB_DISTRIBUTOR=\`( . /etc/os-release; echo \$ ) 2\>/dev/null \|\| echo Ubuntu\`

GRUB_CMDLINE_LINUX_DEFAULT=\"intel_iommu=on,sm_on no5lvl\"

GRUB_CMDLINE_LINUX=\"\"

 

\# grub-mkconfig -o /boot/efi/EFI/ubuntu/grub.cfg

 

\# cat /proc/cmdline

BOOT_IMAGE=/vmlinuz-6.8.0-55-generic root=/dev/mapper/ubuntu\--vg-ubuntu\--lv ro intel_iommu=on,sm_on no5lvl 

 

\# dmesg \|grep -i \'idxd\'

\[    6.288681\] idxd 0000:75:01.0: Intel(R) Accelerator Device (v100)

\[    6.308570\] idxd 0000:f2:01.0: Intel(R) Accelerator Device (v100)
