LKB-000194103

 

Windows key inactivation issue.

ISSUE：

OEM Windows Server 2019 Standard 系统在使用一段时间后提示激活无效提示，系统出厂自带。

再次使用电话激活的时候出现下面提示。

 

![[记录_信息_LKB_记录_005_004-LKB-000194103_001.png]]

 

 

Solution：

通过 slui.exe 0x2a 0xc000002 来确认此code的错误意思。任意一台windwos都可以。

 

![[记录_信息_LKB_记录_005_004-LKB-000194103_002.png]]

 

 

可以通过下面几个步骤进行排查：

1. 通过下图来查找问题。

1）使用 Windows + i 键打开 Windows 设置

2）选择 Update & Security \> troubleoot。

3）转到右侧并单击疑难解答链接。如果 UAC 提示出现在屏幕上，请单击"是"。等待一会儿，直到它扫描并检测到解决方案。

4）然后通过屏幕上的指导方针来尝试解决。

5）最后重启系统看是否能解决激活的问题。

 

 

![[记录_信息_LKB_记录_005_004-LKB-000194103_003.jpg]]

 

 

 

2.启动软件保护服务

0xc0000022错误代码表明您没有适当的权限访问，这就是您在计算机上遇到问题的原因。 如果软件保护服务已损坏或在服务应用程序中不起作用，则会发生这种情况。 要启动此服务，可以使用以下方法。

 

1）单击"开始"，键入 services.msc，然后按 Enter。

 

![[记录_信息_LKB_记录_005_004-LKB-000194103_004.jpg]]

 

 

2）务应用程序中，向下滚动并查找软件保护服务。找到它后，双击它打开"属性"窗口。

 

![[记录_信息_LKB_记录_005_004-LKB-000194103_005.jpg]]

 

 

3）在常规选项卡上，检查服务状态是否为正在运行。如果没有，则单击"开始"按钮以启动服务。单击"应用"和"确定"按钮以保存更改。

 

4）命令启动方式

 

![[记录_信息_LKB_记录_005_004-LKB-000194103_006.jpg]]

 

 

5）如果启动失败，提示权限错误5 拒绝访问，

 

![[记录_信息_LKB_记录_005_004-LKB-000194103_007.png]]

 

将SERVICE 添加到安全，权限改为完全控制，参考如下。

<https://answers.microsoft.com/zh-hans/msoffice/forum/all/%E5%85%B3%E4%BA%8Ewin10%E4%B8%8Bsoftware/6031737f-d219-4488-b355-db198a0af52f>

 

![[记录_信息_LKB_记录_005_004-LKB-000194103_008.png]]

 

 

 

3、运行 SFC 与 DISM 工具进行检查

此检查是为了防止可能是某些系统文件损坏或丢失导致的问题。

已管理员身份运行 sfc/ scannow

 

![[记录_信息_LKB_记录_005_004-LKB-000194103_009.jpg]]

 

这个等待的时间可能会有点长，有可能需要10\~20分钟。

 

接下来，您可以尝试运行 DISM 工具来扫描和修复损坏的"Windows 映像"。 以下是您可以用来执行此任务的步骤。

DISM /Online /Cleanup-Image /RestoreHealth

 

![[记录_信息_LKB_记录_005_004-LKB-000194103_010.jpg]]

 

 

此问题最后是通过第二个方案解决了问题，启动Software Protetion服务后系统恢复到已激活的状态。
