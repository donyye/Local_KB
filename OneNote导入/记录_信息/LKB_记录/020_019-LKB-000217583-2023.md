2023年9月12日

9:30

ISSUE：

There are 4 nodes in the customer vsan cluster, one of the nodes has a problem with storage devices not being refreshed after a new system installation and joining VC. As in the screenshot, clicking on storage devices does not show up.

Restarting the node will work fine, but after a while the same problem will occur again. The other three nodes have not found the same problem.

 

![[记录_信息_LKB_记录_020_019-LKB-000217583-2023_001.png]]

 

 

Solution：

After the problem, try to check in vCenter if storage adapters can find the disk.

You can see it in the screenshot.

![[记录_信息_LKB_记录_020_019-LKB-000217583-2023_002.png]]

 

 

From the vCenter check to see other devices, we found that the BOSS card status is Dead, so we judge that this problem is related to the BOSS card and suggest replacing it.

![[记录_信息_LKB_记录_020_019-LKB-000217583-2023_003.png]]
