LKB-000199695

 

ESXI cannot create a new lun device

 

客户想在存储上创建一个新Lun作为测试用，但是ESXI无法创建新VMFS的错误。

具体操作是在FC 存储上添加了一个新的lun，大小是50M。通过vCenter的存储设备器上也能看到这个新建的50MB 的lun。如下图

The customer wanted to create a new lun on the storage for testing purposes, but ESXI was unable to create a new VMFS device.

This new 50MB lun is also visible on the vCenter Storage.

The following figure shows.

 

![[记录_信息_LKB_记录_008_007-LKB-000199695_001.png]]

现在问题是在vCenter新建数据存储的时候却找不到新建的50M的lun。

Now the issue is that when creating a new datastore in vCenter, the new 50M lun is not found.

 

Solution

此问题的原因是因为lun太小，无法格式化成VMFS。

当把lun调整到50G后解决了这个问题，在新建存储可以发现此lun。

The reason for this issue is that the lun is too small to be formatted as VMFS.

This problem was solved when the lun was resized to 50G, and the lun can be found in New Storage.
