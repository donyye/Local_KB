LKB-000191558

 

VCSA shutdown error message

Issue：

客户发现VCSA在关闭后会出现一个 "FAILED Failed unmounting /storage/log" 的错误提示，想知道原因

 

![[记录_信息_LKB_记录_002_001-LKB-000191558_001.png]]

 

Solution：

通过在LAB测试，在LAB环境里能复现这个问题，关闭VCSA或者重启都会出现这个错误信息。

通过进一步分析，此问题原因是因为 /storage/log是记录VC日志的路径，在关系VCSA的当时还有信息在被记录中，因此无法卸载，所以出现了这个错误提示。

但是这个提示可以忽略 ，再次启动VCSA时没有产生问题。

 

By testing this issue in LAB, the problem can be reproduced in the LAB environment, and the error message appears when VCSA is closed or restarted.

Through further analysis, the reason for this problem is that /storage/log is the path to record VC logs, and there is still information being recorded at the time of VCSA relationship, so it cannot be uninstalled, so this error message appears.

However, this error message can be ignored and no problem occurs when VCSA is started again.
