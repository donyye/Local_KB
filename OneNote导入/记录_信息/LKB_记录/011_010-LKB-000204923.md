LKB-000204923

 

ESXI空间划分问题

 

Issue

 

The customer reinstalled the ESXI system, the current version is 7.0U3. he found a datastore1 with 95.25G of space, and he wanted to know where this space was coming from.

 

![[记录_信息_LKB_记录_011_010-LKB-000204923_001.png]]

 

By checking the vm-support logs, I found that there is nothing unusual about this space size.

 

![[记录_信息_LKB_记录_011_010-LKB-000204923_002.png]]

Solution

Installing system in different size space will have different partition division situation as below, it will be adjusted according to the space.

If the system disk exceeds 138G there will be leftover space, the remaining space can be used as local datastorage.

[https://core.vmware.com/resource/esxi-system-storage-changes#](https://core.vmware.com/resource/esxi-system-storage-changes)
