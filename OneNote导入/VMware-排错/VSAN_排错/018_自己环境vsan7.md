通过命令删除磁盘组。需要先把 ESXI 进入安全模式。

[\[root@localhost:\~\] esxcli vsan storage remove -u 52878c03-74f1-9240-121f-08939c2ff194]

\# 成功运行没有输出

FYI: [https://kb.vmware.com/s/article/2150567?lang=zh_CN](https://kb.vmware.com/s/article/2150567?lang=zh_CN)

 

删除组的时候会把整个磁盘组里的磁盘都一起删除。

删除磁盘组后再重新建磁盘组，node2 就没有磁盘组报错了。

![[VMware-排错_VSAN_排错_018_自己环境vsan7_008.png]]

 

 

修复node3磁盘组

esxcli system maintenanceMode set \--enable true -m ensureObjectAccessibility

进入安全模式，并确保数据可访问

![[VMware-排错_VSAN_排错_018_自己环境vsan7_009.png]]

 

esxcli vsan storage remove \--disk mpx.vmhba0:C0:T4:L0[  \-- ]》删除容量盘

esxcli vsan storage remove \--ssd mpx.vmhba0:C0:T2:L0[   \--]》删除缓存盘

esxcli vsan storage remove -u 5229a8bb-7c36-4664-6c3f-50aea3ffb28a[  \--]》 删除磁盘组

 

退出维护模式：

esxcli system maintenanceMode set -e false

 

 

重新配置磁盘组后正常
