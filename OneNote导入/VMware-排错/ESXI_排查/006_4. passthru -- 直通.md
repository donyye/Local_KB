》客户误把PERC卡直通导致本地盘小时

使用的是ESXI7.x 版本，在 /var/log/boot 可看到ESXI启动过程

从boot log看，HBA卡好像被做成了 passthru。

/var/log/boot

2023-12-11T07:02:32.278Z cpu16:2097722)PCIPassthru: PCIPassthruAttachDev:233: Attached to device 0000:c5:00.0

2023-12-11T07:02:32.278Z cpu16:2097722)Device: 395: PCIPassthru:driver-\>ops.attachDevice :0 ms

2023-12-11T07:02:32.278Z cpu16:2097722)Device: 400: Found driver PCIPassthru for device 0x20f4307f0e09a98

 

而在lspci是能发现这个PERC卡的。

commands/lspci\_-v.txt

0000:c5:00.0 Mass storage controller Serial Attached SCSI controller: Broadcom / LSI HBA355i Front \[vmhba1\]

Class 0107: 1000:00e6

 

\# 这个问题是客户把 hba 卡做错误做成了passthru，导致vsan node的本地盘都没有了。另外 8版本的 boot log好像是 var/run/log/sysboot.log

 

 

》关于passthru GPU 给到VM，VM启动失败

直通 GPU 给到VM后无法开机。提示" 模块"DevicePowerOn"打开电源失败。 无法启动虚拟机。"，但是这个给VM的内存不够大有关系，具体看KB。

<https://www.dell.com/support/kbdoc/en-us/000199172/pci-passthrough-module-devicepoweron-power-on-failed>

 

1. 检查 BUIOS设置

![[VMware-排错_ESXI_排查_006_4. passthru -- 直通_001.png]]

 

2. 添加VM高级参数

pciPassthru.use64bitMMIO          TRUE

pciPassthru.64bitMMIOSizeGB[    128    \--\>  ]或者是 256

 

3. vm 实践预留内存要高与GPU的内存

查看修 passthru 的值，进入到VM后。这是改后的。

grep -i pci ./CentOS-79.vmx

pciPassthru.use64bitMMIO = \"TRUE\"

pciPassthru.64bitMMIOSizeGB = \"128\"
