查看当前系统已挂载的lun状态

esxcli storage filesystem list

 

 该命令用于列出所有卷的信息，包括卷名称、卷 UUID、卷大小、文件系统类型等。

esxcfg-volume -l

 

 该命令用于显示指定卷的详细信息，包括卷的容量、块大小、卷类型等。

vmkfstools -P /vmfs/volumes/\<volume name\>

 

该命令用于列出所有 VMFS 卷的扩展属性，包括卷名称、起始块、结束块、扩展类型等。

esxcli storage vmfs extent list

 

该命令用于列出所有支持的文件系统类型以及每个文件系统的卷名称、UUID、挂载点等信息。

esxcli storage filesystem list

 

该命令用于列出所有卷的名称和 UUID，可以用于查看卷的挂载情况。

ls /vmfs/volumes/

 

查看lun如果有多路径，可看到路径状态，是否有unavailable的路径。

esxcfg-mpath -b

 

[ ESXi ]主机上存储适配器的基本信息

esxcli storage core adapter list

 

列出 ESXi 主机上所有存储设备的信息

esxcli storage core device list

用于移除已分离（detached）的存储设备

esxcli storage core device detached remove -d naa.600000e00d00000000010bc100000000

重新扫描所有存储适配器，以便检测和注册新的存储设备

esxcli storage core adapter rescan \--all
