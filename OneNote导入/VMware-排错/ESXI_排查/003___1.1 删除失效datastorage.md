如何通过VC数据库删除失效datastorage

 

 

如果在ESXI上手动移除或是存储直接移除了datastorage，但是VC上还能看到，可以通过下面的方法进行检查。

 

1. 查看vm是否与这个删除的datastorage有如何关连。如硬盘或正在挂载的 ISO，但没有结果。

 

2\. 通过命令进行删除。要ssh登录到ESXI。

1)列出 ESXi 主机上所有存储设备的信息

esxcli storage core device list

2)用于移除已分离（detached）的存储设备

esxcli storage core device detached remove -d naa.600000e00d00000000010bc100000000

3)重新扫描所有存储适配器，以便检测和注册新的存储设备

esxcli storage core adapter rescan \--all

 

3\. 如果还是不行，就只能到VC上进行删除

<https://vmninja.wordpress.com/2019/04/05/remove-inaccessible-datastore-from-inventory/>

当使用 GUI 和命令都无法删除链接时，可能需要尝试从表中删除数据存储:

 

DELETE FROM vpx_ds_assignment WHERE ds_id=162667;\
DELETE FROM vpx_datastore WHERE id=162667;\
DELETE FROM vpx_vm_ds_space WHERE ds_id=162667;

 

这样做的风险由您自己承担，并确保在删除或更改数据库中的任何内容之前创建 VCSA 的快照或备份。
