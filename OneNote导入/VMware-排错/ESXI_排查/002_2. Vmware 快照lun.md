1. 快照lun (snapshot lun )

快照lun是因为ESXI判定有同一个 UUID的lun，就会判定为快照lun。

 

快照lun在log里的显示：

var/run/log/vmkernel.log

2022-03-07T09:39:39.127Z cpu7:2103706)LVM: 11613: Device naa.6000d31005ae4e00000000000000000d:1 detected to be a snapshot:

2022-03-07T09:39:39.129Z cpu7:2103706)LVM: 11613: Device naa.6000d31005ae4e00000000000000000e:1 detected to be a snapshot:

2022-03-07T09:39:39.130Z cpu7:2103706)LVM: 11613: Device naa.6000d31005ae4e00000000000000000f:1 detected to be a snapshot:

 

进入ESXI 使用命令

esxcli storage vmfs snapshot list

下图是一个case的截图（ST: 1GP5S63 ）

![[VMware-排错_ESXI_排查_002_2. Vmware 快照lun_001.png]]

如果有快照lun就会有输出，如果没有输出是空的。

 

挂载快照lun:

》要挂载在重新启动后保持不变的快照/副本 LUN，请运行以下命令：

esxcli storage vmfs snapshot mount -l label\|-u uuid

For example:

esxcli storage vmfs snapshot mount -l \"\<Volume Name\>\"

esxcli storage vmfs snapshot mount -u \"\<VMFS UUID\>\"

 

》要挂载在重新启动后不持久的快照/副本 LUN，请运行以下命令：

esxcli storage vmfs snapshot mount -n -l label\|-u uuid

For example:

esxcli storage vmfs snapshot mount -n -l \"\<Volume Name\>\"

esxcli storage vmfs snapshot mount -n -u \"\<VMFS UUID\>\"

 

》要对快照/副本 LUN 重新签名（卷在重新签名后立即挂载），请运行以下命令：

esxcli storage vmfs snapshot resignature -l label\|-u uuid

For example:

esxcli storage vmfs snapshot resignature -l \"Volume Name\"

esxcli storage vmfs snapshot resignature -u \"VMFS UUID\"

总结：

快照lun有可能是客户之前为了还原数据而对原来的lun在存储上做的一个镜像，而这个快照与原来的lun是有同一个UUID，所以会导致系统有歧义，它可以通过命令来被ESXI所挂载。
