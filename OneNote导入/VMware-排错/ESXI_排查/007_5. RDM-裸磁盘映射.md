1. 检查磁盘是否支持RDM

localcli storage core device list

![[VMware-排错_ESXI_排查_007_5. RDM-裸磁盘映射_001.png]]

如果支持，是显示 true

Log: cat commands/localcli_storage-core-device-list.txt

 

2. 使用命令做RDM

通过命令方式做RDM\
vmfstools -z /vmfs/devices/disks/naa.xxxxx /vmfs/volumes/datastore1/RDM/rdm1.vmdk \--verbose

![[VMware-排错_ESXI_排查_007_5. RDM-裸磁盘映射_002.png]]

显示 function not implemented ,不支持。

 

3.因为RDM不支持4kn,检查磁盘是512还是4kn

esxcli storage core device capacity list

![[VMware-排错_ESXI_排查_007_5. RDM-裸磁盘映射_003.png]]

格式类型显示是 4kn，但是实际 blocksize 是 512，这个是卡的问题（H965i），所以还是512。在idrac里配置VD的时候也是选的512。

 

另外一台机器，物理和逻辑都是 512，

![[VMware-排错_ESXI_排查_007_5. RDM-裸磁盘映射_004.png]]

 

相关KB： [https://kb.vmware.com/s/article/2091600?lang=en_us](https://kb.vmware.com/s/article/2091600?lang=en_us)

VMFS 6 datastore is required for vSphere deployments and no RDM support is available with 4KN HDDs at this time. (4KN不支持裸磁盘映射)
