[\[root@localhost:\~\] vim-cmd vmsvc/snapshot.removeall 12]

Remove All Snapshots:

\# 删除所有快照

 

[ ]创建快照：

vim-cmd vmsvc/snapshot.create \[VmId\] \[snapshotName\] \[snapshotDescription\] \[includeMemory\] \[quiesced\]

 

例子： vim-cmd vmsvc/snapshot.create 3 SnapshotTest AsnapshotDescription 0 0

[ ]\# SnapshotTest 是快照的名字，AsnapshotDescription 是快照的描述，0是不做带内存的快照，1是带内存快照。后面的0是不开启静默快照，1开启。

 

FYI： [https://kb.vmware.com/s/article/1002310?lang=zh_CN](https://kb.vmware.com/s/article/1002310?lang=zh_CN)
