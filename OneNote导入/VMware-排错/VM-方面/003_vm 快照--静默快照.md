Windows vm 在做静默快照事会失败的问题。经常会出现 2008和之前的系统里，2012 后比较少出现。

 

静默快照是需要 ESXI 和 vm 一起配合才能完成，所以当出现问题的时候vm 系统的 log也是需要检查的。

 

大概过程应该是做静默快照的时候了Windows 会重新生成一个卷，新的数据都写到上面去，然后内存数据会不变做快照，做完后windows再把临时卷的数据合并回去。

 

Windows 主要看系统与应用程序的日志，可筛选 VSS 、VSSAudit 、VSSetup 等字样查查看。
