2. 尝试恢复VM

新建个VM，磁盘先不创建，然后把剩下的磁盘挂过去试试。

在尝试挂的时候发现它是空的，这个是正常的，因为它的磁盘描述文件已经没有了。

![[VMware-排错_VM-方面_005_案例1_ VM 文件丢失_003.png]]

windows2012r2-flat.vmdk 是实践磁盘问，缺少磁盘描述文件。

 

3.使用vmkfstools 来创建描述文件

Vmkfstools -c 536870912000 -d thinmp.vmdk

![[VMware-排错_VM-方面_005_案例1_ VM 文件丢失_004.png]]

 

查看文件内容

![[VMware-排错_VM-方面_005_案例1_ VM 文件丢失_005.png]]

 

改名文件名字为 windows 2012r2.vmdk

![[VMware-排错_VM-方面_005_案例1_ VM 文件丢失_006.png]]

 

再修改文件内容描述，把它改成 windows2012r2-flat.vmdk

![[VMware-排错_VM-方面_005_案例1_ VM 文件丢失_007.png]]

 

 

磁盘描述文件创建好后再添加磁盘就能看到了。

![[VMware-排错_VM-方面_005_案例1_ VM 文件丢失_008.png]]
