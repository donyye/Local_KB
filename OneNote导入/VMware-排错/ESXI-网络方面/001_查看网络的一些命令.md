1. 列出所有驱动的名字与版本\
esxcli software vib list[   ]

2. 查看那些vSwitch与 vmnicX对于

esxcfg-vswitch -l

每个vswitch的信息

esxcli network vswitch standard list

3.如果查看驱动是否在log有没有异常输出可以使用

grep -i \'\'i40e\" /var/run/log/vobd.log

![[VMware-排错_ESXI-网络方面_001_查看网络的一些命令_003.png]]

 

4.查看什么型号的网卡和驱动名字

esxcfg-nics -l

![[VMware-排错_ESXI-网络方面_001_查看网络的一些命令_004.png]]

 

5\. down and up vmnicX

esxcli network nic down -n vmnicX

esxcli network nic list

esxcli network nic up -n vmnicX

 

6. 查看分布式交换机命令

esxcli network vswitch dvs vmware list
