RHEL7.X 共享磁盘

\[root@localhost \~\]# targetcli /backstores/block create block1 dev=/dev/sda5

 

\[root@localhost \~\]# targetcli /iscsi create iqn.2017-08.com.example.rhel7.node1:disk1

 

\[root@localhost \~\]# targetcli /iscsi/iqn.2017-08.com.example.rhel7.node1:disk1/tpg1/portals create 0.0.0.0

 

\[root@localhost \~\]#  targetcli /iscsi/iqn.2017-08.com.example.rhel7.node1:disk1/tpg1/acls create iqn.1994-05.com.redhat:214fc6d75e0

iscsi客户端配置

 

1、安装软件包iscsi-initiator-utils

 

2、重启iscsi服务

 

3、发现iscsi服务器端共享出来的目标

iscsiadm -m discovery -t sendtargets -p 172.17.33.3

 

4、使用iscsi服务器端共享出来的目标

iscsiadm -m node -T iqn.2011-linux-disk1 -p 172.17.33.3 -l

(iscsi共享的目标) (服务器ip) (登录)

 

5、使用fdisk命令查看结果

 

6、解除挂载iscsi共享

iscsiadm -m node -T qn.2011-linux-disk1 -p 172.17.33.3 -u

 

已使用 OneNote 创建。
