Yum 升级系统

2024年4月11日

14:19

 

// 检查可更新的rpm包\
yum check-update

 

// 更新所有的rpm包

\# yum update

 

// 更新所有的包，但是   libsmbios 例外。

\# yum update \--exclude=libsmbios

 

// 查看这个包是否存在

\# yum search httpd

 

// yum理出所安装openssl的版本是那个，还有其它什么版本。（有Redhat yum情况下）

\# yum \--showduplicates list openssl

 

// 指定yum所使用的版本，并查看已安装的openssl版本。

\# yum \--releasever 7Server list openssl \--showduplicates

 

// 下载本地yum源的包到/var/tmp下

\# yumdownloader /var/tmp kernel

 

// 显示隐藏的group组

\# yum group list hidden

 

// 安装开发环境

\# yum groups install \"Development Tools\"

 

// 使用特定的源安装

\# yum \--enablerepo=elrepo-kernel install kernel-xxx

\# yum \--disablerepo=\\\* \--enablerepo=elrepo install kernel-xxx

 

// yum反查安装包

\# yum whatprovides lsb_release 或 yum provides lsb_release

如反查\"lsb_release\"命令是那个安装包提供的。

 

//  将系统跟新到指定的版本

yum \--releasever=7.5 update
