要启用 Red Hat Repo 并使用 Subscription Manager 将系统连接到 RHN 网络，并且当前存在操作系统订阅，必须遵循下面提到的步骤。

 

使用以下命令注册：

\# subscription-manager register\
\# subscription-manager attach \--auto

成功注册后，检查状态（系统是否注册了有效的订阅）

\# subscription-manager status

要查看附加订阅

\# subscription-manager list \--consumed

为了评估完整信息，我们还可以查看位于 /var/log/rhsm 文件夹中的 rhsm.log。

如果您观察到下面列出的出现情况，显然防火墙或代理不允许使用所需的主机名和端口，这会导致系统订阅和 yum 故障，并显示所述的错误消息。

错误：无法建立隧道：403 已禁止

 

可能会看到 [https://access.redhat.com/solutions/3720831。](https://access.redhat.com/solutions/3720831)

![[订阅-升级_005_订阅_001.jpg]]

 

很多时候，由于代理设置或防火墙限制，系统无法访问或链接到 RHN 网络。

 

也可以收集下面列出的命令的输出，以进行更全面的故障排除。

\# curl -v \--proxy proxyiporurl:port [https://subscription.rhsm.redhat.com/subscription \--cacert /etc/rhsm/ca/redhat-uep.pem](https://subscription.rhsm.redhat.com/subscription%20--cacert%20/etc/rhsm/ca/redhat-uep.pem)\
\# curl -v -k <https://subscription.rhsm.redhat.com/subscription/> \--cacert /etc/rhsm/ca/redhat-uep.pem\
\# curl -v <https://subscription.rhn.redhat.com> \--insecure\
\# openssl s_client -connect cdn.redhat.com:443 -CAfile /etc/rhsm/ca/redhat-uep.pem\
\# openssl s_client -connect subscription.rhn.redhat.com:443 -CAfile /etc/rhsm/ca/redhat-uep.pem\
\# curl -v <https://subscription.rhn.redhat.com/subscription/> \--cacert /etc/rhsm/ca/redhat-uep.pem

命令的输出应如下所示。

\# curl -v \--proxy proxyiporurl:port [https://subscription.rhsm.redhat.com/subscription \--cacert /etc/rhsm/ca/redhat-uep.pem](https://subscription.rhsm.redhat.com/subscription%20--cacert%20/etc/rhsm/ca/redhat-uep.pem)

 

以上示例表明，MCAfee 由于与系统策略相关的安全问题而限制对网站的访问。

您需要与贵公司的防火墙和安全团队合作，以允许访问 Red Hat 网站，以便他们可以将这些站点添加到允许的地点并继续。

在防火墙中实施更改后，问题已解决。
