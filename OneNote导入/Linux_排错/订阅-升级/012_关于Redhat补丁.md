可以使用下面命令查看是这个版本是有安装摸个补丁：

使用的是 RHEL9.4：

\# rpm -q \--changelog kernel \| grep CVE-2023-6931

\- perf: Fix perf_event_validate_size() lockdep splat (Michael Petlan) \[RHEL-17969 RHEL-17970\] 

\- perf: Fix perf_event_validate_size() (Michael Petlan) \[RHEL-17969 RHEL-17970\] 

 

使用 \--all 或 -a 参数是代表检测所有的

[\[root@localhost \~\]# rpm -q \--changelog \--all \|grep CVE-2015-20107]

\- Security fix for CVE-2015-20107

\- Security fix for CVE-2015-20107

 

有输出说明是有安装，如果没安装就不会有输出。

 

如果想要安装，请通过下面的方式进行安装：

补丁的更新方法：

<https://access.redhat.com/solutions/10021>

 

例子：

yum update \--cve CVE-2023-6931 

 

 

如果是只想更新到 RHEL9.5 最新版本，但是不想更新到 9.6，如下：

\# yum \--releasever=9.5 update kernel    

![[订阅-升级_012_关于Redhat补丁_001.png]]

 

\# yum update exclude=kernel\* （更新时不更新kernel相关的）

这个用来更新其它所有，但是不包含 kernel。
