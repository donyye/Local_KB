  感谢您将此案例提交至 Linux 域团队。

  在大多数情况下，CVE（公共漏洞和暴露）问题通常通过升级受影响的软件包来解决。针对本案例，我们建议参考 Red Hat CVE 门户网站，以查看每个 CVE 的处理状态。

  以下 CVE 已被修复并在门户中标记为"已解决"：

  - CVE-2025-47273 
  - CVE-2015-20107
  - CVE-2025-4517

   

  客户可按照以下步骤进行验证：

  1.  点击上述链接进入 CVE 页面。
  2.  向下滚动至页面中部，并按产品进行筛选。
  3.  查看受影响的软件包列表。

  例如，软件包 python3.11-setuptools 已通过修复补丁 RHSA-2025:11043 解决。点击该补丁链接可查看更多详细信息。在"更新的软件包"部分中，可以看到该漏洞已通过版本 python3.11-setuptools-65.5.1-4.el8_10 修复。

  我们建议客户评估这些 CVE 的影响，并升级相关软件包至已修复的版本。
