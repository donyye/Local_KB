2024年1月4日

把 xm-idm2.idm.si-en.com 配置成副本服务器(replica)

 

[\[root@xm-idm2 \~\]# cat /etc/hosts]

127.0.0.1   localhost localhost.localdomain localhost4 localhost4.localdomain4

::1         localhost localhost.localdomain localhost6 localhost6.localdomain6

10.10.140.11 xm-idm1.idm.si-en.com xm-idm1

10.10.140.12 xm-idm2.idm.si-en.com xm-idm2

 

[\[root@xm-idm2 \~\]# cat /etc/resolv.conf ]

\# Generated by NetworkManager

search idm.si-en.com

nameserver 10.10.140.11

 

[\[root@xm-idm2 \~\]#]  dnf install ipa-server ipa-client ipa-server-trust-ad samba-client ipa-server-dns -y

 

[\[root@xm-idm2 \~\]#ipa-client-install \--hostname=xm-idm2.idm.si-en.com \--mkhomedir \--enable-dns-updates] \--server=xm-idm1.idm.si-en.com \--domain idm.si-en.com \--realm IDM.SI-EN.COM

 

将副本服务器添加到 ipaservers 组:

[\[root@xm-idm1 \~\]# ipa hostgroup-add-member ipaservers \--hosts xm-idm2.idm.si-en.com]

  Host-group: ipaservers

  Description: IPA server hosts

  Member hosts: xm-idm1.idm.si-en.com, xm-idm2.idm.si-en.com

\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\--

Number of members added 1

\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\--
