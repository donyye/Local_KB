2. 下面错误，DNA范围问题

 

\[root@xm-idm2 \~\]# ipa-healthcheck

\

[  {

    \"source\": \"ipahealthcheck.ipa.dna\",

    \"check\": \"IPADNARangeCheck\",

    \"result\": \"WARNING\",

    \"uuid\": \"11057559-8d7e-4c40-ac03-2a5dcb918b64\",

    \"when\": \"20240905081910Z\",

    \"duration\": \"0.178117\",

    \"kw\": 

  },

 

 

\[root@xm-idm1 \~\]# ipa-replica-manage dnarange-show

xm-idm1.idm.si-en.com: 456200004-456399999

xm-idm2.idm.si-en.com: No range set

 

查看范围要求：

\[root@xm-idm2 \~\]# ipa idrange-show IDM.SI-EN.COM_id_range

  Range name: IDM.SI-EN.COM_id_range

  First Posix ID of the range: 456200000

  Number of IDs in the range: 200000

  First RID of the corresponding RID range: 1000

  First RID of the secondary RID range: 100000000

  Range type: local domain range

 

尝试自己设置范围有错误：

\[root@xm-idm2 \~\]# ipa-replica-manage dnarange-set xm-idm2.idm.si-en.com 456400000-456599999

New range does not fit within existing IPA ranges. See ipa help idrange command

 

 

创建新的 ID 范围：确保新的范围在现有范围之外

\[root@xm-idm2 \~\]# ipa idrange-add IDM.SI-EN.COM_new_range \--base-id=456400000 \--range-size=200000

\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\--

Added ID range \"IDM.SI-EN.COM_new_range\"

\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-\--

  Range name: IDM.SI-EN.COM_new_range

  First Posix ID of the range: 456400000

  Number of IDs in the range: 200000

  Range type: local domain range

 

设置新的 DNA 范围：

\[root@xm-idm2 \~\]# ipa-replica-manage dnarange-set xm-idm2.idm.si-en.com 456400000-456599999

 

查看：

\[root@xm-idm1 \~\]# ipa-replica-manage dnarange-show

xm-idm1.idm.si-en.com: 456200004-456399999

xm-idm2.idm.si-en.com: 456400000-456599999

 

完成后就没有这个错误了。
