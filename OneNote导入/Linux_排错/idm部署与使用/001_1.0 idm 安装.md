1.0 idm 安装

2023年5月8日

16:41

 

 

根据此KB方式进行部署：

<https://access.redhat.com/documentation/zh-cn/red_hat_enterprise_linux/9/html-single/installing_identity_management/index#installing-an-ipa-server-with-integrated-dns_installing-identity-management>

 

1. 安装需要包

\[root@master \~\]#  dnf install ipa-server ipa-server-trust-ad samba-client ipa-server-dns -y

 

2. 修改主机名

\[root@master \~\]# hostnamectl hostname master.idm.domain.com

 

3. 修改host

\[root@master \~\]# cat /etc/hosts

127.0.0.1   localhost localhost.localdomain localhost4 localhost4.localdomain4

::1         localhost localhost.localdomain localhost6 localhost6.localdomain6

10.10.40.10 master.idm.domain.com master

 

4. 修改namserver

\[root@master \~\]# cat /etc/resolv.conf

\# Generated by NetworkManager

search idm.domain.com

nameserver 127.0.0.1

 

5. 使用非交互式命令安装

\[root@master \~\]# ipa-server-install \--realm idm.domain.com \--ds-password P@ssw0rd! \--admin-password P@ssw0rd! \--unattended \--setup-dns \--no-forwarder \--auto-reverse

... 过程这里忽略，可以到 idm 安装过程记录查看...

具体参数可查看KB
