1：安装库：\
\# apt install -y build-essential dkms linux-headers-generic libssl-dev git

build-essential：包含 GCC/G++ 编译器、Make 等基础工具

dkms：动态内核模块支持（用于内核升级后自动重编译驱动）

linux-headers-generic：当前内核的头文件（关键！）

libssl-dev：加密库头文件（某些驱动需要）

git：若源码通过Git获取
