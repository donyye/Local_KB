ISSUES

R860  SUSE12 SP5

1）使用一段时间后，会出现黑屏，鼠标键盘无法使用，idrac虚拟控制界面无法动，到机器现场也无法动。

2）在系统登录界面无法登录，输入密码后会循环到输入密码的界面。

 

此问题，需要检测客户是否有使用 vnc server ，因为这个可能会与 idrac 控制界面有冲突。

 

SUSE 应该使用 xrdp 来做作为远程使用工具。

 

SUSE15 xrdp 的安装：

<https://documentation.suse.com/sles-sap/15-SP6/html/SLES-SAP-guide/cha-configure-rdp.html>

 

 

如果想重启SUSE 桌面：

systemctl isolate multi-user.target \--\> 将停止所有图形相关服务

systemctl isolate graphical.target \--\> 将启动所有必需的GUI服务

Or

systemctl restart display-manager.service

 

=======================================

在Redhat, xrdp 包不由它提供，可以从EPEL或是第三方的库安装，但是不受Redhat支持。\
 

连接到 RHEL 系统的唯一受支持的远程桌面方法是 Virtual Network Computing (VNC)\
[https://access.redhat.com/solutions/275423](https://access.redhat.com/solutions/275423)\
\
 

FYI：

<https://www.nathanobert.com/posts/blog-xrdp-gnome-on-rhel9/>

在RHEL9.2 环境里，可以成功配置

 

dnf install -y <https://dl.fedoraproject.org/pub/epel/epel-release-latest-9.noarch.rpm>

dnf repolist

dnf makecache

dnf -y group install Workstation

dnf install -y tigervnc-server xrdp

systemctl enable xrdp.service

systemctl start xrdp.service

systemctl status xrdp.service

netstat -antp \| grep xrdp

sudo systemctl enable xrdp.service

firewall-cmd --permanent --add-port=3389/tcp

\-\-\-\-\-\-\-\-\-\-\--\
尝试登录没有问题。
