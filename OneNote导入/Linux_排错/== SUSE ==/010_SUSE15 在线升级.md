测试 SUSE15 SP2 升级到 SP5，升级顺序 

SLES 15 SP2 =\> SLES 15 SP4 =\> SLES 15 SP5

 

<https://documentation.suse.com/zh-cn/sles/15-SP6/html/SLES-all/cha-upgrade-paths.html>

 

升级前的准备：

1）备份工作：\
\# zypper lr -e repositories.bak

\# rpm -qa \--queryformat \'%\\n\' \> intalled-software.bak

创建快照，但是需要根分区是 Btrfs 文件系统才可以。

\# snapper create -d \"Before system upgrade\"[   ]\<\--升级前创建快照

\# snapper list[     ]\<\--查看快照

\# \| Type \| Date \| Cleanup \| Description

28\| single \| NOW \| \| Before system upgrade

\# snapper rollback 28[   ]\<\--还原快照

 

2）查看其它信息确认：

\# SUSEConnect -l

 

\# zypper install -y zypper-migration-plugin

or

localhost:\~ \# rpm -q zypper-migration-plugin

zypper-migration-plugin-0.12.1580220831.7102be8-6.4.1.noarch

 

\# zypper refresh

\# zypper lr

\# zypper lu

\# zypper update -y

\# reboot

 

开始升级：

\# zypper migration

开始运行的时候会出现有的模块并没有注册，所以会失败。

 

通过SUSEConnect \--status-text 命令查看那个模块没有注册

![[__ SUSE ___010_SUSE15 在线升级_001.png]]

\
然后注册一下没有被注册的模块\
SUSEConnect -p sle-module-legacy/15.2/x86_64

![[__ SUSE ___010_SUSE15 在线升级_002.png]]

 

然后重新开始升级

![[__ SUSE ___010_SUSE15 在线升级_003.png]]

从这里可以看到有 5个软件将进行升级，然后安装6个新的补丁。问是否同意。

 

![[__ SUSE ___010_SUSE15 在线升级_004.png]]

同意后可以看到问是否要禁用一些过时的库。

正在升级产品SUSE Linux Enterprise Server 15 SP4 x86_64。

发现过时的存储库SLES15-SP2-15.2-0

禁用过时的存储库[SLES15-SP2-15.2-0\[y/n\]]

 

![[__ SUSE ___010_SUSE15 在线升级_005.png]]

1163个包需要升级，11个包需要降级，237个包需要新建，75个包需要删除，4个包需要更改拱形。

总下载大小：1.17 GiB。已缓存：0 B。操作后，将使用额外的150.5 MiB。

注意：需要重新启动系统。
