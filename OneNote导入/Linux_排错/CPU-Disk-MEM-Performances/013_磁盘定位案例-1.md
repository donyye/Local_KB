磁盘定位案例-1

2026年4月15日

10:31

环境：

R760 + H755 Front + Ubuntu24.04

三个HDD磁盘，分别做 RAID0

 

1. 通过"perccli64 /call show AliLog" 命令来确认磁盘的Serial 和 槽位信息。

这里使用 WBMANNDN 来演示

Serial = Vendor Specific

![[CPU-Disk-MEM-Performances_013_磁盘定位案例-1_001.jpg]]

 

 2. 通过"perrccli64 /call/eall/sall show all" 命令来找到此磁盘的组信息。

这里看到 DriveGroup 是 3

DriveGroup[  ]是PERC组建RAID时分配的号

![[CPU-Disk-MEM-Performances_013_磁盘定位案例-1_002.jpg]]

 

3. 通过"perccli64 /call/vall show all"命令来确认VD

这个看到VD是 236

这个里的DG是 DriveGroup[  ]的缩写。

![[CPU-Disk-MEM-Performances_013_磁盘定位案例-1_003.jpg]]

 

4. 相同的命令"perccli64 /call/vall show all"，得知VD 236所对应的 OS Drive Name 是 /dev/sda

![[CPU-Disk-MEM-Performances_013_磁盘定位案例-1_004.jpg]]

 

5. 最后通过 lsblk 命令可以看到sda相关信息

这里 sda 没有做挂载。

![[CPU-Disk-MEM-Performances_013_磁盘定位案例-1_005.jpg]]

 

 

备注：

1）不同的 PERC卡所使用的 perccli 的版本不一样。

2）做 RAID 和 NON-RAID也会不一样。

不同的配置需要具体再看。
