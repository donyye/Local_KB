1. 新建的服务不正常，显示如下图：

导致nfs服务一直无法正常运行

![[RHEL Cluster Test_018_--排错--_001.png]]

 

检查发现，NFS 服务的 nfsd 并没有在同一个 nfsgroup 组里面。所以会导致这个错误。

需要把 nfsd 服务删除，重新在 nfsgroup 组里添加。

 

2. fence 出错，无法运行，如下图显示：

1） pcs status 看到fence是stop状态，fence之前有报错。

![[RHEL Cluster Test_018_--排错--_002.png]]

 

 

2） 试用 ipmitool 测试 idrac 的连通性。从测试反回看是正常的。

![[RHEL Cluster Test_018_--排错--_003.png]]

 

3） 确认正常后清楚 stonith 信息 

![[RHEL Cluster Test_018_--排错--_004.png]]

 

4） 清楚完成后fence状态就自动恢复正常。

![[RHEL Cluster Test_018_--排错--_005.png]]
