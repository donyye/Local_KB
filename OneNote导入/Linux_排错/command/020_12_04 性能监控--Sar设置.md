Sar RHEL7 性能监控 

1\. yum install sysstat

 

2\. vim /etc/sysconfig/sysstat 

HISTORY=30

SADC_OPTIONS=\"-S ALL\"

 

3. 修改运行选项

\# vi /etc/cron.d/sysstat 

\*/1 \* \* \* \* root LC_ALL=C /usr/lib64/sa/sa1 1 1

53 23 \* \* \* root /usr/lib64/sa/sa2 -A 

 

4. 重新启动服务

\# systemctl restart sysstat.service

 

5. 开机启动服务 

\# systemctl enable sysstat

Sar RHEL6 性能监控 

1\. yum install sysstat

2\. vim /etc/sysconfig/sysstat 

HISTORY=28 

3\. 修改运行选项

\# vi /etc/cron.d/sysstat 

\*/1 \* \* \* \* root LC_ALL=C /usr/lib64/sa/sa1 -I -d 1 1 

53 23 \* \* \* root /usr/lib64/sa/sa2 -A

4\. 重新启动服务

\# /etc/init.d/sysstat restart 

5\. 开机启动服务 

\# chkconfig sysstat on
