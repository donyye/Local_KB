03.1 route

2025年4月21日

12:59

查看路由表\
ip route\
\
添加默认路由

ip route add default via 192.168.1.1 dev eth0

 

添加带优先级的默认路由

ip route add default via 192.168.1.1 dev eth0 metric 10

\# metric 是优先级，数字越小优先级越高

 

修改现有默认路由的metric值\
ip route change default via 192.168.1.1 dev eth0 metric 1

 

删除路由

ip route del default

 

多路径路由

ip route add 192.168.2.0/24 via 192.168.1.1 dev eth0 via 192.168.1.2 dev eth1

\# 多路径路由允许数据包通过多个路径到达同一目的地，这可以提高网络的冗余性和负载均衡。
