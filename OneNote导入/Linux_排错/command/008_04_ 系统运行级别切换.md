04: 系统运行级别切换

2023年9月7日

8:59

可以使用下面的命令切换到"运行级别3 "：

systemctl isolate multi-user.target 或 systemctl isolate runlevel3.target

可以使用下面的命令切换到"运行级别5 "：

systemctl isolate graphical.target 或 systemctl isolate runlevel5.target

 

 

systemctl get-default    #查看当前模式

systemctl set-default multi-user.target   #修改启动使用3模式，多用户。

systemctl set-default graphical.target  #修改启动使用5模式，图像。

 

 

runlevel[  \#]查看运行在那个级别

 

 

graphical.target      #图形

multi-user.target    #多用户字符

rescue.target          #单用户

emergency.target  #救援模式

 

在 kernel 启动的过程中可以切换启动模式。

systemd.unit=emergency.target

modprobe.blacklist=nouvan

 

 

journalctl -u gdm[  \# ]查看 gnome 服务状态。

systemctl list-unit-files \|grep enabled  #查看随机启动的服务列表

systemctl list-units \|grep -i fail \#查看系统启动后失败的服务

 

 

kernel 启动顺序

\# grub2-editenv list   \--\> 查看当前默认启动kernel

# cat /boot/grub2/grub.cfg \|grep menuentry     \--\> 查看有那些kernel在grub里。

\# grub2-set-default \'Red Hat Enterprise Linux xxxx\'  \--\> 设置默认启动的kernel，重启生效。
