02: nmcli 配置网络

2023年7月11日

15:38

配置IP地址：

\# nmcli con mod ens192 ipv4.addresses \"10.10.40.182/16\" ipv4.method manual autoconnect yes

 

添加一个网络设备：

\# nmcli con add con-name ens193 ifname ens193 ipv4.addresses \"192.168.100.182/24\" ipv4.method manual type ethernet  autoconnect yes

 

添加默认路由：

ipv4.routes \'default 172.16.13.254\'[  \<\-\-- ]添加172.16.13.254 网关为默认的路由

手动添加： ip route add default via 172.16.13.254 dev ens35

 

配置 team：

==server==

nmcli con add con-name team0 ifname team0 type team config \'{\"runner\":}\'

nmcli con mod team0 ipv4.address \"192.168.0.101/24\" ipv4.method manual

nmcli con add con-name team-port1 ifname eth1 type team-slave master team0

nmcli con add con-name team-port2 ifname eth2 type team-slave master team0

nmcli con up team0

ip a

teamdctl team0 state

==desktop==

nmcli con add con-name team0 ifname team0 type team config \'{\"runner\":}\'

nmcli con mod team0 ipv4.address \"192.168.0.102/24\" ipv4.method manual

nmcli con add con-name team-port1 ifname eth1 type team-slave master team0
