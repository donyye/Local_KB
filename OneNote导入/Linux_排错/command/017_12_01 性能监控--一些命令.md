磁盘iostat监控：

iostat -xmzd 1 \| while read pong; do echo \"\$(date): \$pong\" \>\> /tmp/iostat.log ; done

x- 显示详细信息 \| x- 显示详细信息 \| z- 告诉 iostat 忽略采样期间没有活动的任何设备的输出。\| d- 显示设备利用率报告。

ping [www.163.com](http://www.163.com) \| while read pong; do echo \"\$(date): \$pong\" \>\> /tmp/ping.log ; done
