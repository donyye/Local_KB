2024年2月19日

1、自建yum源：

yum-downloadonly

yum install httpd \--downloadonly \--downloaddir=/var

 

1）#yum install createrepo

 

2）[\[root@open \~\]# vim /etc/yum.repos.d/my-yum1.repo]

 \[my-yum1\]

 name=my-yum1

 baseurl=ftp://192.168.0.249/nginx-32/

 gpgcheck=0

 

3）[\[root@open \~\]# createrepo -p -d -o /var/ftp/nginx-32/ /var/ftp/nginx-32/]

 23/23 - php-xml-5.2.17-15.el5.i386.rpm

 Saving Primary metadata

 Saving file lists metadata

 Saving other metadata

#-p 路径 ；-d 目录 ； -o out

 

4）如有新包添加，自动更新库。

createrepo \--update /var/ftp/nginx-32

5）指定摸个yum源安装软件。

yum install XXX \--enablerepo=YYY

XXX是要安装的软件，YYY是repo源的名字。

或者屏蔽所有yum源，只用其中一个yum源安装:

 yum \--disablerepo=\\\* \--enablerepo=my-yum1 install nginx

 

6 )yum 安装所有软件

yum install \\\*

\-\-\-\-\--

有时候在yum的时候好慢,很多工作都停留在yum这里,有瓶颈,后来发现yum-fastestmirror插件,非常好用,他会选择最好的mirror进行下载

# yum install yum-fastestmirror -y
