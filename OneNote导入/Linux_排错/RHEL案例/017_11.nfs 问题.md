一个 RHEL9.1 + HA + NFS

![[RHEL案例_017_11.nfs 问题_001.png]]

客户端挂载问题

 

共享了一个nfs

[\[root@localhost mnt\]# showmount -e 10.10.40.100]

Export list for 10.10.40.100:

/nfsshare/share01 10.10.40.0/255.255.0.0

 

 

使用 nfs4 下面方式挂载会失败

[\[root@localhost mnt\]# mount -vvv -t nfs4 10.10.40.100:/nfsshare/share01 /mnt/date3]

mount.nfs4: timeout set for Mon May 13 15:09:12 2024

mount.nfs4: trying text-based options \'vers=4.2,addr=10.10.40.100,clientaddr=10.10.40.222\'

mount.nfs4: mount(2): No such file or directory

mount.nfs4: mounting 10.10.40.100:/nfsshare/share01 failed, reason given by server: No such file or directory

 

但是不指定 nfs4 版本就能挂载成功

[\[root@localhost mnt\]# mount -vvv -t nfs 10.10.40.100:nfsshare/share01 /mnt/date3]

mount.nfs: timeout set for Mon May 13 15:07:32 2024

mount.nfs: trying text-based options \'vers=4.2,addr=10.10.40.100,clientaddr=10.10.40.222\'

mount.nfs: mount(2): No such file or directory

mount.nfs: trying text-based options \'addr=10.10.40.100\'

mount.nfs: prog 100003, trying vers=3, prot=6

mount.nfs: trying 10.10.40.100 prog 100003 vers 3 prot TCP port 2049

mount.nfs: prog 100005, trying vers=3, prot=17

mount.nfs: trying 10.10.40.100 prog 100005 vers 3 prot UDP port 20048

 

[\[root@localhost mnt\]# mount \|grep nfs]

10.10.40.100:nfsshare/share01 on /mnt/date3 type nfs (rw,relatime,vers=3,rsize=1048576,wsize=1048576,namlen=255,hard,proto=tcp,timeo=600,retrans=2,sec=sys,mountaddr=10.10.40.100,mountvers=3,mountport=20048,mountproto=udp,local_lock=none,addr=10.10.40.100)

 

修改挂载方式：

[\[root@localhost mnt\]# mount -vvv -t nfs4 10.10.40.100:/ /mnt/date3]

mount.nfs4: timeout set for Mon May 13 15:09:42 2024

mount.nfs4: trying text-based options \'vers=4.2,addr=10.10.40.100,clientaddr=10.10.40.222\'

 

[\[root@localhost mnt\]# mount \|grep \'date3\']

10.10.40.100:/ on /mnt/date3 type nfs4 (rw,relatime,vers=4.2,rsize=1048576,wsize=1048576,namlen=255,hard,proto=tcp,timeo=600,retrans=2,sec=sys,clientaddr=10.10.40.222,local_lock=none,addr=10.10.40.100)
