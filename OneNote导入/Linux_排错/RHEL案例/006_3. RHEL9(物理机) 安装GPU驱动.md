安装前的参数讲解

\#[  -no-x-check ]跳过对X server的检查强制安装，不管 X 服务器是否运行。

\# -no-nouveau-check 跳过对 nouveau 驱动的检查。

\# -no-opengl-files[  ]只安装驱动文件,不安装 OpenGL 库。

========== 不重新安装系统的方法 ===============

Ubuntu:

[\[root@localhost \~\]#] cd /etc/X11/

[\[root@localhost X11\]#] ls

applnk  fontpath.d  nvidia-xorg.conf  xinit  Xmodmap  xorg.conf  xorg.conf.d  Xresources

[\[root@localhost X11\]#] mv nvidia-xorg.conf nvidia-xorg.conf.bak

[\[root@localhost X11\]#] mv xorg.conf xorg.conf.bak

[\[root@localhost X11\]#] cd xorg.conf.d/

[\[root@localhost xorg.conf.d\]#] ls

00-avoid-glamor.conf  99-nvidia.conf

[\[root@localhost xorg.conf.d\]#] mv 00-avoid-glamor.conf 00-avoid-glamor.conf.bak

[\[root@localhost xorg.conf.d\]#] mv 99-nvidia.conf 99-nvidia.conf.bak

 

在一个 RHEL9.2 案例中只在"/etc/X11/xorg.conf.d"下发现 nvidia.conf 配置文件，修改后系统能成功进入图形界面

\# cd /etc/X11/xorg.conf.d

mv 10-nvidia.conf 10-nvidia.conf.bak
