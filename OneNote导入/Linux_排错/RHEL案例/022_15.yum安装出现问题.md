15.yum安装出现问题

2025年5月9日

17:15

 

 

配置的是 本地 yum，但是在安装 httpd 的时候无法成功，报下面的错误。

 

截图错误信息：

![[RHEL案例_022_15.yum安装出现问题_001.png]]

文字信息：

\[root@R660 \~\]# yum install httpd

Updating Subscription Management repositories.

 

This system is registered with an entitlement server, but is not receiving updates. You can use subscription-manager to assign subscriptions.

 

Red Hat Enterprise Linux 9 for x86_64 - BaseOS (RPMs)                                                                                                                                  0.0  B/s \|   0  B     00:57    

Errors during downloading metadata for repository \'rhel-9-for-x86_64-baseos-rpms\':

  - Curl error (6): Couldn\'t resolve host name for <https://cdn.redhat.com/content/dist/rhel9/9/x86_64/baseos/os/repodata/repomd.xml> \[Could not resolve host: cdn.redhat.com\]

Error: Failed to download metadata for repo \'rhel-9-for-x86_64-baseos-rpms\': Cannot download repomd.xml: Cannot download repodata/repomd.xml: All mirrors were tried

 

解决方法：

1. 清楚所有 /etc/resolv.conf 里的所有dns设置。

2. 使用下面命令清楚所有系统注册信息

\[root@R660 \~\]# subscription-manager remove \--all

Network error: Name or service not known (error code -2)

 

\[root@R660 \~\]# subscription-manager unregister

Unregistering from: subscription.rhsm.redhat.com:443/subscription

Network error: Name or service not known (error code -2)

 

\[root@R660 \~\]# subscription-manager clean

All local data removed
