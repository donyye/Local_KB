5. 系统上的订阅导入

然后把这个证书传到系统里

 

![[RHEL案例_011___6-1 手动添加离线订阅_007.png]]

 

开始导入

 subscription-manager import \--certificate=/tmp/export/entitlement_certificates/2669258727498828525.pem

 subscription-manager import \--certificate=/tmp/export/entitlement_certificates/2360949375000946775.pem

 subscription-manager import \--certificate=/tmp/export/content_access_certificates/4059697959802916806.pem

![[RHEL案例_011___6-1 手动添加离线订阅_008.png]]

 

最后通过命令验证导入是否成功

subscription-manager list \--consumed

备注：

当通过 \# subscription-manager register 注册在线系统时，它会在客户门户网站中自动创建一个连接的配置集；而在注册离线系统时，会在门户网站中手动创建一个断开连接的配置集。

完成此步骤后，客户门户网站中的系统配置集将显示订阅状态为 \"Unknown\"，命令 \# subscription-manager status 将输出 \"Unknown.\" 这是预期的行为。如需更多信息，请参阅[离线系统注册的订阅状态为\"Unknown\"](https://access.redhat.com/solutions/2158251)
