9. 驱动问题导致无法up p4p1

2024年1月10日

17:28

 

客户的系统是 Oracle Linux 7.8 ，有一张 Inter 的网卡X710，驱动名字是 i40e

使用 ip add 无法看到此卡

![[RHEL案例_015_9. 驱动问题导致无法up p4p1_001.png]]

 

![[RHEL案例_015_9. 驱动问题导致无法up p4p1_002.png]]

 

1. 使用 lspci 能看到网卡，说明系统已经让到此网卡

\# lspci -vvv \|grep -I \'ethernel\'

![[RHEL案例_015_9. 驱动问题导致无法up p4p1_003.png]]

 

在idrac也看到

![[RHEL案例_015_9. 驱动问题导致无法up p4p1_004.png]]

 

2. 手动去配置一个 p4p1 的配置文件

![[RHEL案例_015_9. 驱动问题导致无法up p4p1_005.png]]

 

但是up网卡的时候还是有错误

![[RHEL案例_015_9. 驱动问题导致无法up p4p1_006.png]]

 

![[RHEL案例_015_9. 驱动问题导致无法up p4p1_007.png]]

 

3. 查看message log

![[RHEL案例_015_9. 驱动问题导致无法up p4p1_008.png]]

看到错误说好像这个p4p2不存在。

 

手动添加 i40e 驱动也不行。驱动是inbox的驱动。

![[RHEL案例_015_9. 驱动问题导致无法up p4p1_009.png]]

 

最后检查到的问题：

因为 inbox的驱动无法支持此 X710 的卡，后来把系统的kernel升级更高的版本，自然inbox驱动也一起被升级了，然后重启系统就能加载此卡了。

或者安装新的驱动也可以解决
