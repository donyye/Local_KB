4. 单用户模式

2022年7月14日

12:06

 

启动在kernel项选择e编辑，写入 rd.break

![[Linux引导修复_005_4. 单用户模式_001.png]]

 

在单用户的模式下 chroot /sysroot 进入到系统根目录

\# 这个命令的意思是："以这样的方式启动一个新的 shell，对于那个 shell，/sysroot 目录将显示为 /。\"

无法使用 df -h 命令，需要重新 mount \--rbind xxx 一些目录。

![[Linux引导修复_005_4. 单用户模式_002.png]]

\# exit   \<\--执行这个命令可以退出 chroot 环境

\# mount \--rbind /proc /sysroot/proc

\# mount \--rbind /sys /sysroot/sys

\# mount \--rbind /dev /sysroot/dev\
\# mount \--rbind /run /sysroot/run\
\# chroot /sysroot

完成后就能执行系统基本命令。

 

这个时候的 / 还是只读的状态，可以重新挂载一下

mount -o remount,rw /sysroot

 

如果系统有开启SElinux那做了什么修改最后需要 

touch /.autorelabel 

\# 让机器重启的时候重新按照 selinux 的数据库标签给整个文件系统打上标签。

 

 

如果重启有SELinux报错，可以启动时强制停止它

enforcing=0
