1. 安装KVM

\# dnf install \@virt -y

\# lsmod \|grep kvm

 

- 还需要安装有用的虚拟机管理工具：

\# dnf -y install virt-top libguestfs-tools

 

- 安装virt-manager工具，该工具允许从GUI管理虚拟机

\# dnf -y install virt-manager

 

2. 启动

\# systemctl start libvirtd

\# systemctl enable \--now libvirtd
